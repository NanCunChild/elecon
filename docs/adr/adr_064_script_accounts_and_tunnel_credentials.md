# ADR-064 脚本账号声明与 App Tunnel 账号配置

- 日期：2026-11-02
- 状态：Accepted（本轮所有者要求统一脚本账号需求，并在设置配置应用内隧道凭证）；实现验证与人工审阅另记。
- 承接：ADR-034/035/044/052/062。

## 脚本账号

SDK 11 在 manifest 必填 `accounts`（0–16 项）。每项包含包内稳定 `id`、`name`、`instructions`、依赖该账号的 `capabilities` 及可选 `login: {capability, params?}`。账号 ID 唯一，能力必须由同包声明，登录参数限 4 KiB JSON；文字有界且为纯文本。外部或共享登录由 instructions 说明，无 login 时不显示登录按钮。空数组明确表示不需要账号，不出现账号字段的 SDK 1–10 仅表示尚未声明，不能据其凭据数量猜测。

这只是受授权 digest 覆盖的说明及前台调用绑定，不授予新权限、不限制同校凭据访问，也不增加账号密码模板或学校协议到核心。设置按当前 Profile/学校的已安装脚本列出需求、用途、说明与登录按钮；禁用/需更新的包只供查看。登录固定原包及 digest，不经能力覆盖重新选择来源，离页/切身份/撤销取消本次调用。学校认证、睿思、学习通保留各自协议与存储；账号存在或登录调用成功不推导其他服务已认证。

SDK 1–10 原始包及 digest 保留；SDK 11 需新版本并重新安装批准。既有 `generic.section`、`forum.session`、`messages.session` 登录可作为绑定，不新增业务数据 schema。模板和打包器与 Dart 解析同步更新。

## 隧道凭证

扩展 ADR-062 首片的仅网页登录界面：允许用户在设置输入网关、可选节点证书指纹、用户名、密码及可选认证域。核心将账号单独保存在当前 Profile/学校 H/S/M 存储，UI 仅取得网关/账号名/认证域与是否已保存，不返回密码。普通脚本不能读取隧道账号或会话。

保存与认证分离。空密码仅可保留同一网关/用户名/认证域的原密码；修改身份需重新输入。保存账号或清除配置撤销旧会话与在途连接；失败不报告保存成功。主动“使用已保存账号登录”执行一次 Hermes 密码流程，认证域省略时仅接受网关提供的唯一密码域，多个域要求用户指定。验证码、MFA 或不支持密码的网关返回固定的需要交互提示，用户可主动转用官方网页登录，不自动提交或重试密码。成功需完成 reportEnv/authCheck、onlineInfo 与 sid 核验，再发布受保护会话；不把保存账号当已登录。

取消、切学校/Profile、退出、账号修改及更新令晚到认证失效；持久化失败回滚内存记录并报告固定错误。TLS、DNS、origin/IP、目标证书、V1 门与不回落直连沿用 ADR-062，不新增系统 VPN 或依赖。旧仅会话配置无需迁移，仍能网页登录/使用/清除。

## 验证与回滚

校验声明版本、重复 ID/越界能力/参数上限及 digest 变化；设置覆盖脚本独立来源、禁用、旧包与中英文。隧道验证账号加密恢复、跨学校/Profile及脚本不可读、空密码语义、错误输入、持久化失败、取消和认证单次性。只使用合成数据/本地协议夹具，不连接真实学校网关。回滚可由用户选择直连或清除隧道配置；SDK 11 包需兼容宿主。核心/凭据/网络实现仍待人工实质审阅后合并。

# ADR-097 · 存储驱动的注册入口与前台调度

- 日期：2026-11-05
- 状态：Accepted（所有者要求落地核心原语，并同时开放脚本侧注册及定时调用 API；实施证据另记）
- 承接：ADR-046、080、081、087；讨论见[执行原语研究](../research/script_execution_primitives.md)。

## 决定

SDK19 增加页面拥有的执行作用域。初次调用仍进入 `capabilities[id](ctx, params)`；脚本可将批准模块的 `handlers` 导出中的稳定名称注册给核心。后续调用只解析该名称并创建新 QuickJS 实例，不保存函数对象、闭包、旧 ctx 或可变模块内存。处理器只接收本次宿主 ctx，通过 `ctx.execution.stateKey` 从作用域存储读取业务状态。注册和预约参数不接受业务参数快照。源码常量、普通辅助函数及单次执行内的局部变量不受此限制。

`ctx.execution` / `elecon.execution` 只在宿主显式开启的作用域中提供：`state.get/set/delete`、`register({id, handler, stateKey})`、`unregister(id)`、`schedule(id, at)`、`cancel(id)`。`at` 是 Unix 毫秒时刻。初始调用的 stateKey 为 null，注册调用为登记的键；trigger 区分 initial/manual/timer。宿主也可按登记 id 按需调用。注册不执行、预约不占住运行队列、每个 id 最多一个待执行预约；取消预约不删除注册，删除注册同时取消预约。

一个作用域固定学校身份、批准包 digest、业务数据代际和原始 capability。处理器产出仍按该 capability 的版本化输出契约校验，只定向返回所属消费者，不获得切换身份、来源或输出契约的能力。该切片允许只读前台续订（card.qr 或已声明 home 查询），拒绝命令、账号登录和交互能力；自动触发禁输入/浏览器交互。脚本须遵守原始查询的只读含义，宿主不能由函数名字证明任意受信源码无副作用。用户启用的写操作计划仍需 ADR-080 的持久领取、未知结果和恢复机制。

存储仅在作用域内存中存活，单项 JSON 最多 64 KiB、最多 32 项、合计 256 KiB；最多 16 个注册。状态只接受普通 JSON，缺失明确报错，不回退到闭包。单次执行的状态、注册与预约先暂存，输出校验与宿主持久化成功且作用域仍有效后才提交；失败不启动下一轮。预约距离登记时刻为 1 秒至 24 小时，超过目标 30 秒尚未开始则记为 missed，不追赶或补发。每个作用域串行，重复手动触发在忙时拒绝；全局仍沿用已有执行队列，不新增并行凭据快照。

离页、后台、退出、切学校/身份、更新/禁用来源或登录导致业务代际变更，销毁作用域、内存状态及计时器，并取消排队和在途调用。生命周期取消与来源变化分开：恢复前台可在同身份、同批准来源和同业务代际下新建作用域，不沿用旧状态。取消不能撤回已发送的远端请求；失败和未知结果不自动重放。

## 卡片状态与广播

本轮不引入通用事件总线。已有查询缓存保存数据，`homeDataRevision` / Session 通知让一级摘要和详情重新读取同身份、来源及参数的快照；二维码是单个页面拥有的临时输出，不进入持久缓存。注册调用的结果使用作用域的定向状态通知。课表仍先按新鲜度拉取，再更新缓存；通知不负责发现源站变化。

未来多个独立消费者确需共享状态时，优先细化“存储快照 + 键/版本通知”，保证订阅与初读不丢更新。只有每条事件都必须保留时才引入持久事件流及其顺序、重复、确认规则。按钮命令不广播，避免多消费者重复提交。

## 迁移与验证

包格式和业务 schema 不变，SDK19 与旧 SDK1–18 分界；旧宿主拒绝新 SDK，新宿主保持旧短调用和二维码续订兼容。学校包升版并重新批准 digest。处理器结果不自动写旧查询缓存，避免将没有标准查询参数的处理器输出放到错误的缓存键下；初始 capability 调用保持原缓存规则。

本片不提供后台常驻、进程重启恢复、系统唤醒或脚本互相广播，也不改变 V1 门。验证真实 QuickJS 跨执行状态隔离、非法注册/JSON、额度、替换/取消/错过、失败停止、排队撤销、来源与身份失效、旧 SDK 兼容及二维码生命周期。实际学校、真机后台行为和核心人工审阅独立记录。回滚终止 SDK19 作用域，新包在旧宿主明确不可执行。

# ADR-079 · 院校分组、身份类型与有界学校标题

- 日期：2026-11-03
- 状态：Accepted（所有者要求学校主标题、类型副标题及长标题排版；实现与验收分别记录）
- 承接：ADR-035、041、043、070、076。

## 学校展示与身份边界

SDK16 增加可选 `manifest.school = {id, name, type:{id,name}}`。`school.id` 是展示院校的分组标识，`school.name` 是学校主标题；`school.type.id` 标识该包服务的学生/身份类型，`school.type.name` 是副标题。id 使用既有小写 identifier 规则且最多128字符；校名最多160个 Unicode 字符，类型名最多80个，均为非空纯文本、禁止控制和双向控制字符。两个对象只接受上述必填键，完整字节纳入批准 digest。

这些字段只影响目录分组与标题，不改变执行授权身份。原有 `manifest.schoolId` 继续绑定凭据、安装、缓存、网络选择与退出范围。西电本科和研究生显示同一院校 `xidian`，分别使用 `undergraduate`/`postgraduate` 类型；已有 `xidian_undergraduate`/`xidian_postgraduate` 安全范围保持原样。切换类型仍按切换授权身份撤销旧执行和重新检查账户；相同展示院校不授予跨类型凭据访问，也不复制、合并或删除旧记录。后续真正统一授权范围必须另有迁移决策、明确用户选择与账号重新验证。

学校和类型名由受信包提供，宿主不从包名括号或学校特例猜测。已有学校描述仍由原选中基础来源拥有，增强包安装不得抢占标题。SDK15及以下拒绝新字段，未声明的旧包保持原 name/homeTitle 行为。新字段存在时首页校名取 school.name、类型名显示副标题，不用旧 homeTitle 再拼接身份类型；包名仍在安装审查与脚本管理中完整保留。

## 页面责任

宿主提供固定分级选校：院校名作为主项，身份类型作为其下选择项；选择动作仍指向确定的包与原授权范围。内置未安装目录可用核心翻译呈现校名及类型，安装后以批准包元数据为准。已安装未知学校按显式 school.id 分组，未声明则保留独立条目；不因相同显示文字合并学校。

首页学校主标题始终单行。使用当前主题字号与系统文字缩放测量，先缩小到固定最小逻辑字号，再对仍超宽的文字提供水平来回滚动与首尾停顿。最小字号仍接受系统缩放，不用整体缩放抵消无障碍字体。RTL 从阅读起点开始，滚动和命中区域一致；屏幕阅读器只读完整标题一次。关闭动画偏好时禁自动移动，用户仍能手动横向滚动并读取完整语义。

动画只在可见前台页面的 TickerMode 启用时运行，进入后台、页面遮挡、尺寸/文字/方向变化及销毁都停止或重新计算；不发网络请求。较短校名无动画。类型副标题独立换行，不挤占或混入校名，也不截断账号/脚本身份审查字段。全套实现不增加依赖。

## 验证与回滚

验证分组不影响原 schoolId、不同类型凭据仍隔离、来源更新不抢标题、旧包兼容；标题覆盖缩小/滚动、RTL、文字缩放、减少动态效果、前后台/路由及销毁。测试只用合成身份。回滚学校包需恢复原批准版本；展示字段不产生存储迁移或授权合并。真机排版观察与真实学校账号验收独立记录。

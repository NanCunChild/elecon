# ADR-083 · 查询表单的可选字段延迟加载

- 日期：2026-11-04
- 状态：Accepted（用户授权减少筛选等待、异步补充教室类型及原生布局优化）
- 承接：ADR-082；不新增 SDK、网络权限或学校专用核心分支。

## 决定与边界

脚本负责静态目录、学校时区与默认时间、何时需要网络、选项取数和最终业务校验。核心仅提供通用的可选字段延迟解析、原生时间选取器及表单生命周期。西电首屏与普通依赖刷新使用包内南北校区/教学楼目录，网络仅用于显式查询或可选的教室类型补充；目录更新随学校包重新授权，不宣称静态目录永远与官网一致。

`query.controls` 输出与参数升级为 2.1，保留 2.0 和 1.0 精确快照。字段新增可选 `deferred: true`，表示当前只有字段声明，尚不可呈现或提交。只能用于非必填、没有 initialValue 的叶子字段；其依赖必须是同表单普通字段。disabled 的 deferred 字段不加载。字段总数、选项、输出大小等沿用 2.0 限制。

参数增加 `load?: string[]`（1–32 个唯一字段 id）。普通调用仍返回基础表单，宿主显示基础字段后按需发起同来源的只读补充调用，current 仅含请求字段及其声明依赖的有效草稿值。脚本返回完整表单以复用现有校验，宿主只采用本次请求字段：id/kind/dependsOn 必须保持一致，仍须非必填且无 initialValue，deferred 必须解除；其他字段、标题和提交文案不被补充结果替换。一次补充不继续触发补充链，不自动重试。

尚未解析且无已有值的字段隐藏，不影响基础条件提交；加载失败显示简短重试入口，仍可查询。打开已有查询时，未解析字段的已选值必须保留并显式标为等待确认，允许用户清除；不能在用户不知情时丢掉既有条件或把未经选项验证的值提交。只有这类已有条件等待确认时才阻止提交，清除后立即可提交。依赖改变清空对应下游草稿及解析结果，隐藏该字段，丢弃旧响应；无关字段编辑不重新加载或覆盖用户草稿。补充失败不破坏基础表单。

基础元数据失败仍按 2.0 保留草稿、重试并阻止使用失效必填字段提交。来源、批准 digest、Profile、数据代际、语言变化与窗口关闭使所有迟到响应失效。补充读取是无交互元数据请求，不写业务缓存；点击提交可取消未完成补充的宿主会话等待，不等待其网络完成，也不声称撤回已发送 HTTP。

## 页面与学校行为

空教室仅保留统一筛选入口，结果直接呈现教室及其占用区间；已有 intervals.reason 显示在占用块及其提示中，不新增更精确来源数据。删除结果下方第二组筛选与选中教室的纯文字详情，教室属性归入对应行，来源与覆盖信息保留。旧包筛选能力按旧协议维护，不给核心增加学校字段识别。

timeRange 使用原生时间选取器；学校脚本提供默认起止时刻，核心不从字段名推断业务。西电起点为学校当前分钟，终点为后 60 分钟并限制在 23:59；23:59 无合法同日区间时不提供默认整段。新 filters 时段若不与任何已知课程节次相交，结果为未知而不是空闲；旧顶层时间参数含义保持。

## 迁移与验证

西电包升 0.28.1，声明 query.controls 2.1；旧宿主拒绝未知版本，更新仍需检查包内容并重新批准 digest。2.0/1.0 包保持原有加载及提交语义，不向其发送 load/deferred。

验证基础表单不等待补充、失败仍可提交、已有选择的保留/清除、依赖变化与迟到结果、无关编辑不重取、不允许补充改变基础字段或增加必填条件、取消/身份变化、原生时间选择；学校验证首屏零网络、内置目录、后台类型与最终值校验、时区和日末边界。组件与真机可视化分别记录，不以合成测试替代真实学校或人工核心审阅。

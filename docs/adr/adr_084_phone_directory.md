# ADR-084 · 电话黄页与原生拨号入口

- 日期：2026-11-04
- 状态：Accepted（所有者请求电话黄页卡片、包内静态号码和点击通话）

## 决定

新增只读 `directory.phones` 1.0 和原生 `directory` 卡片。电话目录与教师检索、通知、登录结果有不同含义，不复用这些能力；不把拨号编码成 generic link 或脚本命令。

参数为封闭的空对象。输出包含完整 `items`（最多 2000 条）、目录 `sourceUrl` 和 `verifiedDate`（作者核对公开页面的日历日，不代表学校确认电话有效）。每条包含包/学校内稳定 `id`、服务名称 `name`、`category`、可拨号码 `phone` 和公开 `sourceUrl`；可选 `campus`、`address`、`note`。号码是带可选前导加号的 3–15 位数字，不含 USSD、分机或 URI；多个号码分条返回，本地区号由学校脚本基于来源补全。没有已核实号码的来源不能用虚构号码占位。失败不能返回假空目录。

客户端本地按名称、类别、校区和号码搜索，提供来源与核对日期。点击号码调用系统 `tel:` 处理程序，由系统电话应用继续操作；展示、缓存、刷新不拨号。失败显示固定提示并允许复制号码。不申请直接通话权限，不向脚本开放任意 URI 启动能力。使用 Flutter 官方 `url_launcher`（pub.dev，BSD-3-Clause）。目录可声明只读 home 缓存；来源、身份、digest 和取消复用已有机制。

西电本科/研究生包共享静态目录，以 tel.xidian.cc 及其链接的学校公开办事指南为来源，收集时保留页面出处及未能核实的页面记录；运行时不抓站、不读凭据。公开办公联系方式是产品数据，不作为真实学生测试夹具。

## 版本与迁移

新增能力/schema/card 类型，无已有字段改义，不提升 SDK。学校包升版并重新批准 digest；旧宿主拒绝未知能力/卡片，新宿主继续支持旧包。回滚学校包可移除卡片与能力。学校号码和解析规则不进入宿主。

## 验证

验证输出/schema/生成物、非法号码、重复身份、来源绑定、身份变化和迟到结果、搜索/空结果、拨号仅由点击触发、无处理程序的失败与复制。真实设备拨号和人工核心审阅单列，不能用自动测试替代。

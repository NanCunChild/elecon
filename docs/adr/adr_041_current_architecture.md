# ADR-041 当前架构基线与文档治理

- **Decision**：Accepted（2026-10-31，所有者本轮明确要求重新规划文档、归档旧 ADR/AGENTS）。
- **范围**：文档治理和已存在路线的基线承接；不是对全部未来接口设计的接受。
- **Landing**：本次文档迁移；运行时代码不因本文变更。
- **安全签收**：不新增或替代任何实现签收。ADR-034–040 各自的实现、平台与人工验收状态继续独立记录。
- **取代**：ADR-000–033 作为项目默认总纲的地位及旧 AGENTS；有效共享语义和未退役 V1 约束按 §3 承接。

## 1. 问题与范围

当前主线已采用用户授权的受信学校源码脚本，旧总纲仍从官方签名 bundle、凭据不可见、requestGraph 与单卡片模型开始讲解。逐页添加路线例外无法让读者确定默认入口。文档也把 schema 存在、客户端有页面、服务器已实现、实际可用混为一谈。

本轮将旧说明放入 `docs/archived/2026-10-31/`，明确废弃为新开发依据。旧路径只留迁移提示；旧 AGENTS 使用非指令文件名保存。历史正文保留决定和签收事实，只调整相对链接、清理行尾空白并加档案标记。原本已有的 `docs/archive/` 不重搬。

## 2. 当前基线

学校脚本负责认证和数据归一；客户端负责本地安装授权、当前身份、背景运行、网络范围、取消、标准输出校验和原生 UI。ADR-035 的同校 namespace 仍不是访问控制。脚本可以使用授权的宿主 HTTP/浏览器能力，不获得任意原生能力。

能力声明、标准数据和页面职责分别讨论：一个业务页面可以展示多个能力，同一份数据可供首页摘要与独立详情使用。继续使用客户端固定组件、Material 3 与 l10n，不增加远程布局语言；不再把“一 schema 一首页主卡片”作为新页面规划的硬约束。现有 manifest 仍按能力匹配 schema，页面注册、增强包组合与新实体模型的具体契约留给 ADR-042，本文不改 schema 或 SDK。

私密查询以客户端直连为基线。现有 public 是静态分发端点、campus 是 501 stub；新受信脚本目前仅在客户端生产执行，不能沿用“一份脚本已在两端运行”的描述。公开数据统一缓存和校内授权查询是不同服务范围，见研究与后续规划。

## 3. 从历史 ADR 继承的有效约束

| 历史来源 | 当前承接内容 | 适用边界 |
|---|---|---|
| 001、019、025 及领域增量 | 已存在的 schema 字段、数据版本、课室/外链语义、标准输出验证 | 未经新 ADR 不能改义；实际契约以 `contract/` 为准 |
| 004 | 固定客户端渲染、主题、无任意 Widget tree | 取消将新页面固定为首页卡片的规划限制；现有组件保持兼容 |
| 003、005、008、010、012 | 编译内传输、背景执行、平台存储、平台分发边界 | 不因文档归档扩权，不宣称跨平台已验收 |
| 002、009、013–018、020、022–029、031、033 | V1 验签、凭据不可见、Broker/Masker、DEV 门及原有未完成状态 | 只约束尚存 V1，不重新推动其新增功能 |
| 030 与 040 | 命令确认、非幂等失败未知、禁静默重试、平台边界 | 新源码控制以 040 为准；公共缓存不能代理控制 |
| 006、007、032 等未实施方案 | 历史 deferred/proposed 状态 | 归档不代表接受或准许实现 |

[兼容维护边界](../reference/legacy_compatibility.md)集中维护仍存旧代码的职责；安全缺陷仍需修复，移除旧入口须有使用与依赖证据。

## 4. 文档和状态规则

[AGENTS](../../AGENTS.md)是协作入口，[architecture](../architecture.md)是当前架构入口；[ADR 索引](README.md)维护决策，`planning/trusted_scripts.md` 维护现行实现，`planning/platform_evolution.md` 维护后续切片。研究报告提供依据，不自行覆盖 ADR。

ADR-034–040 保留原编号与接受记录；本轮不把原有未提交的 ADR-040/水电实现混入文档提交。档案标注 superseded/archived 表示退出新开发指引，不擦除历史 Accepted、人工签署或未签收事项。新提案单独标 Proposed，验收必须附可追溯证据。

## 5. 验证与代价

核对迁移清单、档案标记、相对链接、活动入口、Git diff 和待提交范围。旧路径保留跳转，旧章节锚点须转到历史正文；不依赖全文旧文档继续充当规则。文档迁移不需要运行学校接口或重跑与之无关的全量产品测试。

代价是暂时保留一批跳转页；收益是代码注释和外部链接可追溯，而新贡献者不再从退役总纲推断新 SDK 的行为。

# ADR-038：脚本声明首页缓存与静默预加载

- **Decision**：Accepted（2026-10-30；所有者本轮要求脚本指定带时间戳缓存、登录后预加载与隐形刷新；不等于人工安全签收）
- **范围**：ADR-034 受信源码包、当前学校本地数据缓存及固定首页；不改变 V1 路径、公网服务或业务输出 schema。

## 1. 声明与行为

SDK 4 manifest 可选 `home` 数组（最多16项），每项为 `capability`、`ttlSeconds`（30–86400）、可选 `params`（JSON对象，编码不超过4096字节）和 `preload`（默认false）。能力必须已在同包声明且不重复。TTL由脚本作者决定，宿主记录成功取数完成时间，不能把读缓存或刷新失败当成新数据。旧SDK不接受此扩展；包内容与更新仍须用户确认digest。

宿主仅缓存声明能力通过标准schema校验后的输出，按学校身份、脚本id、批准digest、能力和规范化参数区分。默认参数与显式参数分别寻址，最近参数结果可供固定卡片恢复。每条含fetchedAt、TTL及数据；过期先展示、后台重新验证，超过7天不再展示。手动查询会取新数据，失败保留原成功结果与原时间。学校脚本可通过无参能力自行选择当前教学周，宿主不理解校本参数。

## 2. 本地保护与清除

缓存复用已经选择的H/S/M后端，以不可作为凭据API地址的 `script-cache:` 保留键和 `script-data` 类型保存。它们不属于登录凭据，不计入登录状态或凭据登记界面，脚本凭据API不能寻址此键。UI只收到重新通过schema校验的业务输出与时间，不取得后端、凭据或密钥。S档保持原知情同意语义，M档只存内存，不新增明文数据文件或公网路径。

每条最多512KiB、每学校最多32条且合计4MiB，超限按最老成功时间淘汰；异常记录当miss处理。登出/重置沿当前身份清除；禁用/卸载/更新不再读取旧digest，运行中的晚到结果不得写入。切校不展示其他学校数据。重启仅在原H/S后端可解密时恢复。

## 3. 预加载与刷新

登录成功、首页进入/恢复前台、前台每分钟检查和显式刷新可触发 `preload:true` 项目。未过TTL的项可直接复用；显式刷新可强制重取。并发刷新合并，同一会话执行仍串行，跨身份/安装代际取消。非交互调用墙钟预算35秒、HTTP请求最多20次；应用暂停或页面销毁时停止前台周期检查。每项独立失败，不妨碍其它卡片。

后台刷新一律非交互：不弹浏览器、输入框或存储许可，不自动打开验证码页面；需要交互则保留缓存，等待用户显式登录或查询。后台无前台刷新动画，成功且数据或时间改变后通知卡片更新。无缓存时保留现有手动查询和三态。

## 4. 验证

覆盖参数规范化、TTL/时间不伪新、持久化恢复、大小/淘汰、学校和digest隔离、登出与晚到回调、失效数据重新校验、静默刷新无交互及卡片销毁重建恢复。所有夹具合成；自动测试不替代核心和存储路径人工审阅。

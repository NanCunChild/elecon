# ADR-056 首页前台请求卡片

- **Decision**：Accepted（2026-11-02，所有者要求签到进入主页，核心使用通用卡片及现有扫码能力）。
- **Landing**：本轮实现通用前台请求组件与签到薄绑定；自动回归、设备与真实活动验收分别记录。
- **范围**：承接 ADR-043/045/046/052/055；不新增 SDK、manifest 字段、数据契约或宿主权限。

首页可为已有前台能力展示入口，沿用宿主 `SectionCard`、尺寸与显隐配置。入口的发现和呈现只读取安装状态，不执行脚本。打开功能页后，用户显式点击按钮才触发普通受信请求；账户登录同样显式触发，绑定签到来源包自身的 `messages.session`（若有），不借用其他来源的账号。

`ForegroundRequestSection` 复用单次请求、忙碌互斥、固定来源、失败和结果呈现、取消与生命周期。签到薄绑定只解释现有 `attendance.checkin` 状态/原因和 1.1 地点参数；学习通二维码、认证、网络协议和活动要求留在学校脚本。`generic.section` 仍是只读标准数据，不能隐式变成动作协议；本轮没有通用任意按钮描述或脚本下发组件树。

只在功能页运行；首页预览、打开页面、编辑布局和地点均不提交签到。一次点击只发起一次能力调用，不自动重试或回退来源，不写 home 缓存。切身份、来源更新、退出页面、隐藏或暂停应用时撤销当前调用并清除临时结果、选中地点。相机/登录表单作为调用期间的子路由不会误触发离页取消；以所属路由被弹出作为退出依据。

现有宿主日志清理及有界日志通道继续适用；页面不得把源站正文、QR、凭据或位置作为诊断记录。未知提交结果保留，不以通用错误鼓励自动重发。

回滚移除首页入口及组件即可；学校脚本与旧消息页签到继续按原契约执行。验证覆盖零预加载、连续点击互斥、同包账号、返回/后台/身份失效、扫码子路由和旧 1.0 地点隐藏。真实签到结果及核心人工实质审阅不由自动回归替代。

2026-11-02 自动验证：新增 6 项 Flutter/真实 QuickJS 组件回归通过，覆盖首页和打开页面的零自动调用、同包显式登录、单次扫码、扫描子路由、忙碌互斥、应用隐藏/返回页面/来源禁用后的晚到结果拒绝，以及 1.0 地点隐藏。现有首页布局和地点组件 13 项回归通过。新文件静态分析及 diff 空白检查通过；以上均为合成数据，不表示真机或真实活动验收。

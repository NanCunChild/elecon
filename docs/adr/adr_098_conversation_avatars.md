# ADR-098 · 会话头像与群名称兜底

- 日期：2026-11-05
- 状态：Accepted（所有者要求新增群图像与群名称的核心及脚本功能；实现仍需人工审阅后合并）
- 承接：ADR-061、063、066。

`messages.conversations` 输出升为 1.3，新增可选 `avatarImages`：有序的 0–4 张 PNG/JPEG 缩略图 data URI，每张解码后至多 16 KiB，宿主单次返回的解码总量至多 1 MiB。缺失表示本次未取得，核心可保留同一身份和来源下已有图像；空数组表示明确清除。单图铺满，多个图像由原生组件拼接；图片失效显示默认群/联系人图标，不显示破损图标。不增加任意 URL、附件操作或图片点击入口。

图片由学校脚本通过已有授权 HTTP 取得；核心只消费内联字节，不从 UI 再发网络请求，不使用全局网络图片缓存。脚本仅请求明确列入新包网络声明的 HTTPS 图片来源，不携带 IM token/Cookie，不跟随重定向；未知来源省略图片。宿主原有 TLS、网络、预算、取消及隧道策略继续适用。包升版并重新批准 digest，SDK 和参数版本不变；保留输出 1.0/1.1/1.2 的精确快照，旧包扩展字段不解释为头像。

超星脚本继续批量读取已加入群的详情，显式群名优先；空白或 `_<groupId>` 后缀的占位群名用群主、管理员、成员的去重顺序取最多四个资料显示名，已知超过四人追加省略号；资料不足保持已有有效名称或稳定 ID，不伪造完整成员名单。头像按相同顺序使用成员资料的 pic120/pic，课程封面不充当群头像。每次最多补充 64 个群的成员样本、500 份联系人资料和 64 张去重缩略图，超星包全部 data URI 文本合计至多 1 MiB；只读可选补全失败不清空目录，认证失效、取消和资源限制仍中止调用。

缩略图连同名称进入现有 Profile/学校/包 digest/服务账号绑定的受保护 SQLite 快照。合并规则保留缺失头像、接受显式清空；会话正文总量超过 1 MiB 时先移除最旧会话头像，保留会话身份与标题，仍遵守 4 MiB 总库和 30 天保留界限。退出、禁用、更新和身份变化沿用原有清理及迟到结果门。

协议事实参考本地 Quasar-core 的 `research/xidian/DATA_SOURCES.md` 第 7–8 节（研究文件尚未提交，基线和文件摘要见[研究记录](../../school-scripts/xidian-chaoxing/research/README.md)）及[环信官方群详情](https://doc.easemob.com/document/server-side/group_obtain_detail.html)/[Web SDK](https://doc.easemob.com/apidoc/web/modules/Group.html)资料；独立实现，不复制 GPL 实现或引入新依赖。课表候选只作独立研究，不把默认当前周接口冒充现有整学期含调课数据，不改变生产默认课表来源。

验证覆盖占位群名、成员排序去重、大整数、错误群/联系人 ID、图片来源和凭据隔离、非法/超限图片、可选失败及认证/取消、旧版本忽略、保护存储恢复/清除与原生拼图降级。合成回归和性能模型不是学校实测；真实图片域、用户 token 的群成员访问权限、实际课表完整性/耗时和真机另验。回滚恢复旧包和客户端，旧输出契约继续准入。

# ADR-086：门户入口与绑定详情页

状态：Accepted（2026-11-04，按本轮用户授权实施）。

首页卡片是一级摘要与入口，所有宽度均采用有限高度；搜索与筛选属于二级页面。相同实例固定学校、包 digest、卡片 ID 和页面，不在打开时重新选 provider。

SDK18 将只读 home 声明上限从16扩为32（SDK1–17维持原上限），以容纳新增服务摘要；仍逐项遵守预加载与命令门。SDK18 增加可选 pages：每项 id、title、template（原生卡片类型、forum、messages、web）、可选 tab（默认 false）及 webPageId（仅 web 必需）。页面声明本身不授权执行；必须拥有模板能力，webPageId 必须指向同包已有 webContent。cards 可选 pageId 显式绑定同类型页面；generic 卡片可绑定任意同包页面作为兜底。省略保持既有绑定。宿主最多显示三个脚本 tab，其余仍可从首页进入；固定首页/设置保留，作者不能指定任意路由或参数。旧SDK拒绝新字段，SDK18旧宿主拒绝安装。原有forum/messages默认tab仅在包未声明pages时保留。

网页模板复用当前受控web.content容器及其网络/生命周期限制；本次不宣称ADR-080长期作者JS已落地。

过滤器复用ADR-082/083表单在详情内联渲染；草稿不执行业务查询，显式提交或首次打开的只读默认查询才执行。缓存恢复优先，不以空列表覆盖失败。profile名称消费已有profile.me.name，不改变身份主键或凭据寻址。

验证：manifest/schema正负例、旧SDK拒绝、来源失效、绑定关系、widget布局与只读查询。回滚撤销SDK18包授权并恢复旧包；用户原布局不迁移。自动检查不代替核心人工审阅。

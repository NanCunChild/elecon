# ADR-101 · 页面缓存刷新与个人课表

- 日期：2026-11-10
- 状态：Accepted（所有者授权缓存、课表、导出及自定义课程实施；不代表人工核心审阅或真机验收）
- 承接：ADR-038/048/054/089/090/099。

一级摘要和二级详情先恢复同身份、批准来源 digest、语言和参数的快照；有快照时不清屏。通用缓存组件在前台对过期快照发起一次静默只读刷新，TTL 到期和前台恢复重新检查，失败保留原值和原始取得时间；同一快照失败不循环重试，手动刷新及重新进入可重试。取消、来源更新、登录数据代际变化继续撤销迟到结果。仅已有 home 缓存声明的查询参与，命令、账户、二维码与前台社区能力不得自动执行；无快照的查询仍依照已有预加载、配置和用户触发规则。

课表整学期缓存保留期从通用 7 天改为 180 天，TTL 和容量上限不变，过期仍显示 stale；不把旧学期投影到新日期。桌面仅消费缓存，在已知今日无课时展示未来六日中的下一次已知课程，并区分缺数据与已知无课。Android H/S 的已授权 scope 可持久记录为不含学校名称的 opaque allowlist，进程重建后在解锁状态读原有加密快照；身份/来源变化先持久撤销 allowlist 再清快照。M 不持久化，锁屏仍遮蔽。

个人课程是原生宿主拥有的本地数据，按 Profile（已有存储后端）及学校隔离，属于该 Profile 的个人规划，不随某个脚本 digest 或学校登录票据替换。保存在 H/S/M 同一受保护库的宿主保留地址，不向脚本开放。用户显式添加/删除，和当前周标准课程组合展示、导出，不修改学校返回值或其缓存时间，不向学校写入。首次实现为单日课程，可重复添加；不引入 SDK 或契约字段。

导出使用 RFC 5545 iCalendar：按明确课程日期、学校时区输出事件，过滤停课及周例外，实体 UID 稳定、文本转义、UTF-8 折行。用户选择单周或缓存中完整学期；未知日期/学校时区不猜测设备时区。支持选择提前分钟数，生成 DISPLAY VALARM；用户主动保存并导入系统日历后，由所选日历应用负责提醒。应用本轮不声明通知或精确闹钟权限，不承诺日历应用一定执行 VALARM；重新导出不自动更新外部日历。导出文件由用户选择目的地，明确含课程和地点。

学校脚本拥有节次到墙钟映射；教学展示分段可将两小节合为大节，不改变每门课程的原始开始/结束时间含义。按用户提供的西电作息更新学校包并升版本，等待重新批准 digest，不把用户参考时刻当作已完成真实学校验收。

验证覆盖静默刷新失败保留、身份/参数/来源变化取消、学期缓存长期 stale、个人课程持久化及隔离、导出日期/周例外/取消/转义/时区/提醒、桌面未来课程和进程恢复。主题和安装检查使用 Material 3 色彩、层级及滚动容器。剩余真机/日历兼容及核心人工实质审阅记录在统一实施计划。

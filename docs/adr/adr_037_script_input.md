# ADR-037：脚本主动请求有界原生输入（SDK 3）

- **Decision**：Accepted（2026-10-30；所有者本轮明确要求由脚本决定何时、哪些字段需要补填，并提供通用弹窗接口；实现细节由本文限定，不等于人工安全签收）
- **范围**：新受信源码 SDK 与固定客户端工具弹窗；继承 ADR-034/035 的身份、授权、后台执行与取消规则，不扩展 V1 Broker 能力。
- **依据**：ADR-004 §2、ADR-034 §3/§5/§6、ADR-035 §2–§4；红线 #1/#4/#5/#6/#7/#8。

## 1. 决策

SDK 3 新增 `await ctx.ui.requestInput({title, message?, fields})`。脚本决定调用时机、字段标识与说明；宿主负责固定 Material 表单，不解析学校专有错误码来决定补填。提交返回所有字段的字符串键值映射，取消返回 null。脚本自行验证校本含义、选择继续/终止及是否通过当前身份凭据 API 保存；宿主不自动持久化输入、不把填写内容加入后续业务 params。

字段为固定 text/password/select 三类；每项含 id、label、type（默认 text）、required（默认 true）、maxLength（默认 128，上限 4096），可选 initialValue；select 声明 options（label/value），不支持任意 Widget、HTML、脚本验证正则、事件回调或网络资源。password 不允许初始值，宿主固定遮挡并关闭建议/自动纠错。输入不是执行任意原生 UI 的能力。

一次请求最多 8 个字段，select 最多 20 个选项，id/选项值不能重复；请求 JSON 最多 32 KiB，标题/标签最多 120、说明最多 1000 字符。宿主在显示前严格校验请求，在交还脚本前复验结果；字段类型/键/选择范围/长度/必填错误不进入脚本。每次调用最多 8 次表单请求，拒绝并发表单；这些调用仍计入 256 次宿主调用与既有执行预算，不以重试隐藏突破上限。

弹窗固定显示“学校脚本请求信息”、当前安装包名称和学校身份，提交/取消文案由宿主提供。脚本标题/说明/字段标签作为受信脚本数据展示；它们不是系统身份声明。浏览器不是此接口的前提，不分配 Cookie 租约，也不要求 browser=true。

## 2. 执行与取消

表单异步跨 QuickJS isolate；主界面只收到已校验的请求及当前包身份，不收到完整凭据库或主密钥。返回值只属于当前调用。切校、登出、禁用、卸载、更新、页面销毁、超时和调用取消均关闭弹窗；晚到提交不能继续网络/凭据写入。用户取消表单返回 null，脚本可选择结束或其它路径；不以无输入自动查询第一项或伪造身份。

SDK 3 的交互调用由现有会话队列串行；无 presenter 时只在实际请求输入时报 input_unavailable。SDK 3 的会话总时限使用既有 120 秒交互上限，HTTP 请求预算仍按浏览器权限分 40/20 次。显示表单不暂停、重置时限，不启动隐藏浏览器。

所有提交字段值在交还 JS 前加入本次调用的日志秘密集合；不输出原始请求/提交内容/异常文本。仅用固定 input_invalid_request / input_invalid_result / input_unavailable / input_busy / input_limit / input_cancelled 类别报告失败。此净化沿用 ADR-034 的局限，不能防止受信脚本主动编码泄漏。

## 3. 版本与迁移

包格式继续 elecon-script/1；SDK 3 保持 SDK 2 完整凭据描述符与寻址，新增 UI 请求。宿主与工具显式支持 1/2/3，未知版本仍拒绝；旧客户端在安装/解析 SDK 3 时拒绝，不等到运行后才发现能力缺失。SDK 1/2 不注入 ctx.ui，不改变其凭据语义。SDK 3 内容仍须版本提升、用户重新确认 digest。

共享首页移除按 card/student 错误码自动弹窗并重跑的学校字段补丁。新版西电脚本缺学号时自己请求并保存；无卡号余额/流水依据已确认 ADR-036 直接显示，不调用表单。旧 SDK 1/2 的错误码可继续显示，但不再触发宿主猜测字段；需升级脚本或显式提供运行参数。默认登录仍使用学校原页，不将此输入 API 用于重新接入 PDA 密码代请求。

## 4. 验证与审阅

真实 QuickJS 验证请求/提交/取消、无浏览器场景、输入值日志净化、严格请求与结果、并发/次数限制、SDK 门和长字符串桥接。Widget/会话覆盖表单渲染、密码遮挡、select、可选字段、取消/销毁/切校/超时关闭以及晚到提交无效；两个不同学校的相同字段不串用。学校回归覆盖脚本主动补学号和无卡号查询；契约类型、输出校验和 V1 回归保留。自动检查不能替代人工对核心/凭据路径的实质性审阅或真机验收。

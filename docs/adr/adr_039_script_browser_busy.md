# ADR-039：脚本浏览器登录收尾提示（SDK 4）

- **Decision**：Accepted（2026-10-30；所有者本轮要求缩短 Cookie 收割延迟，并允许脚本指定“正在登录”遮罩防止误触；不代表人工安全签收）。
- **范围**：ADR-034 受信源码的浏览器宿主；继承 ADR-035/037 的身份、取消及执行预算，不改变 V1 路径。

## 1. 决策

SDK 4 增加 `await ctx.browser.setBusy(boolean)`。脚本决定认证进入收尾的时机；宿主只显示固定、可翻译的“正在登录”提示和进度指示，并阻挡学校页面的触摸、键盘焦点及语义交互。标题栏“关闭并取消”和系统返回继续可用。提示文字、Widget、HTML 和布局不能由脚本指定；遮罩不是认证成功的证据，也不自动保存 Cookie 或宣告登录完成。

遮罩状态属于当前浏览器调用，跨已授权导航保持，脚本可显式关闭。失败、拦截和关闭清除遮罩，以展示固定错误和允许用户处理。调用仍受浏览器权限、网络范围、当前身份撤销、256 次宿主调用和原有墙钟预算约束；非 boolean 请求拒绝。不创建隐藏浏览器，不新增原生能力或浏览器关闭接口。

开启遮罩时同时清除 Flutter 焦点、学校页面当前 DOM 焦点、Android/iOS WebView 原生焦点并关闭输入法；遮罩期间新文档导航完成后再次清焦点。关闭遮罩不自动恢复旧输入框焦点，由用户重新点击。平台键盘行为仍需真机复测。

## 2. 西电登录收尾

正式 IDS 登录采用独立的有界采样：认证端点验证成功后立即开启遮罩，两次完整路径 Cookie 快照至少相隔 250ms，认证页与 Cookie 集合保持一致才保存。Cookie 顺序不参与稳定性；登录/MFA 页面、空 Cookie、旋转和导航中断不能作为成功。旧浏览器业务登录保留原有采样预算。IDS 保存后继续验证 CAS 交换和真实教务 API，再结束调用；业务失败不能覆盖旧业务会话。

## 3. 版本与验证

SDK 1/2/3 不注入新方法，SDK 4 保留旧 API；旧宿主通过包 SDK 门拒绝新版包。源码变更提升版本并重新确认 digest。无需新依赖或业务输出 schema 改动。

覆盖真实 QuickJS SDK 门与参数、原生桥接生命周期、遮罩阻挡页面且取消可用、导航保持与错误清除，以及合成 IDS Cookie 稳定/旋转/MFA/取消和业务失败。自动回归不替代真机验收或核心人工安全审阅。

# ADR-087 · 一卡通前台二维码续订与详情恢复

- 日期：2026-11-04
- 状态：Accepted（所有者要求进入一卡通立即加载二维码、保持更新、点击显示及返回恢复查询）
- 承接：ADR-038、047、066、080。

一卡通一级卡片只展示概要，用户进入绑定来源的二级页面后依次看到余额、固定高度二维码区域与消费统计。二维码默认模糊，点击后显示；加载与更新不依赖解除遮罩。点击统计进入同一来源的消费明细。

二维码前台使用现有只读 `card.qr` 短调用连续续订，每次仍经过原有执行 digest、身份、网络、资源预算及取消门。续订时间取脚本 `expiresAt` 有效期内且最长 60 秒，自动请求禁交互，不引入无限执行或后台计划。离页、后台、切身份、来源失效立即清理图片与定时器；返回有效前台重新取得二维码，重新遮罩。失败停止续订并提供手动重试，不自动重放命令。图片不写业务缓存。

交易与教师查询从现有受保护查询缓存恢复参数、结果及原始时间。交易分页按同一日期窗口依次恢复已缓存页，缺页停止，不把单个后续页冒充完整统计；刷新失败保留同一查询的已有结果，切换日期窗口则清空旧窗口。教师查询恢复最近一次已提交参数，不因页面展示发起空查询。学校包须显式声明相应缓存策略；不改变身份、digest、语言与数据代际隔离。

验证覆盖自动续订、后台/离页清理、过期和迟到图片拒绝、遮罩、查询缓存恢复与刷新失败、分页完整性。回滚为旧详情布局不改变 schema。真实学校二维码有效性与核心人工审阅单列。

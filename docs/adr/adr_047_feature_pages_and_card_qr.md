# ADR-047 功能入口、课表视图与校园卡二维码

- Decision: Accepted（2026-11-01，所有者要求本轮实现）。
- Landing: 功能页、周课表/今日时间线、独立校园卡二维码已实施；空教室进入搜索与请求去重已实施，真实静态教学楼目录仍待提供。

## 决策

普通首页点击打开原生功能页面，不临时改卡片尺寸或格位。编辑模式菜单仍可选择尺寸。页面固定打开时的会话代际；来源/身份变化后清除旧内容并要求返回。页面和首页复用标准模型、查询实现与会话缓存。已有 v4 布局无需迁移。

课表页面复用 schedule.week 1.0：七日横轴、时间或节次纵轴，同一时段冲突课程均可查看；未知标签保留为列表，不猜测墙钟时间。首页大卡片只显示今天的线性课程时间线；日期无法确定时明确提示，不能将历史周的同一星期冒充今天。校历和周次查询继续使用现有能力。

新增 card.qr / elecon.card.qr 1.0，返回学校给出的 PNG base64、生成/取得时刻和显示截止时刻。截止时刻表示客户端必须停止显示的上界，不承诺学校在此期间一定接受二维码。只在用户打开后查询，不加入 home 预加载或持久缓存；页面隐藏、后台、身份/来源变化、超时后清除。不得将图片 URL 交给 UI 发起鉴权请求。没有新增付款提交或充值操作。

校园卡模板按独立的 card.balance / card.transactions / card.qr 能力组合；余额继续保留原 1.0 必填 balance 含义，无消费能力的学校只声明二维码，无需伪造零余额。卡片展示建议允许任一校园卡能力。已有 SDK 可声明注册能力，无需增加宿主 API；旧宿主没有新 schema 时拒绝未知结果，新宿主保留旧能力。

空教室继续使用 classroom.buildings / classroom.available，学校可在脚本内打包非私密楼名与查询代码，宿主不硬编码学校目录。打开页面自动准备目录，直接展示搜索条件；查询不重复获取楼目录。尚未获得真实目录时不得编造代码，保留来源发现兼容路径并明确记录此限制。

## 验证与回滚

使用合成数据验证导航不重排、周课表/今日日期与重叠课程、搜索准备、PNG 非法输入/过期/后台清除、二维码学校没有消费区块。学校脚本验证实际 DOM 解析与请求次数；契约同步 registry、schema、生成类型与 CHANGELOG。回退客户端仍可使用旧学校包，升级学校包须重新授权 digest。核心与网络实现仍待人工实质审阅后合并。

## 实施验证（2026-11-01）

全量 Flutter 回归 **1339 项通过、11 项跳过**。覆盖原生导航返回保留已选条件与业务状态、学校/来源变化、编辑模式、深浅主题/大字号、今日日期判定、重叠课程、独立二维码布局、过期/后台清除以及真实 QuickJS 的学校 PNG 协议与输出校验。学校脚本 9 个测试文件通过；二维码 schema/包语义 smoke、原有包校验与打包 smoke、生成物检查与 tools TypeScript 检查通过。

数据均为合成，不请求真实学校或付款设备。没有新增依赖；课表视觉参考 PDA 的七日网格与每日时间线，由本仓库原生组件实现；学校二维码协议改写保留 campus.js 的 MPL-2.0 来源声明。西电静态教学楼目录不是本轮已完成内容，不使用合成代码代替学校代码。回滚旧包仍需保留原有 digest 安装授权。

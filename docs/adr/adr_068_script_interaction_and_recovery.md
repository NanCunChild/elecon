# ADR-068 · 脚本交互声明、认证恢复、网页模板与语言资源

- 日期：2026-11-03
- 状态：Accepted（所有者要求功能补充与精确分层；设计接受不表示全部接口已实施）
- 承接：ADR-034、037、039、041、046、066、067。
- 实施状态：[功能补充切片](../planning/feature_supplements.md)。新增声明以实际 SDK 为准，未实施部分不得写入生产 manifest。后续 [ADR-070](adr_070_script_localization.md) 在 SDK13 实施包语言资源，[ADR-071](adr_071_script_query_controls.md) 实施有限查询条件；[ADR-072](adr_072_saved_password_recovery.md) 和 [ADR-073](adr_073_packaged_web_content.md) 在 SDK14 实施账号密码/事件和包内表单。不能宣称旧 SDK 已有这些接口；隐藏恢复与远端网页网络覆盖仍未开放。

## 1. 分层与函数

| 层 | 拥有的事实 | 接口责任 |
|---|---|---|
| 平台端口 | 原生 WebView、网络、受保护存储、系统 AI | 不识别学校 Cookie 名、认证算法、课程字段 |
| 宿主 | Profile、学校、批准 digest、前后台、取消、预算 | 每次执行及异步返回重新核对代际；强制声明边界 |
| 会话 | 来源绑定、账号状态、查询缓存、恢复合并 | 协调一次恢复，过滤过期事件，不保存明文密码到 UI 状态 |
| 学校脚本 | 多个业务函数、认证、错误判定、DOM、翻译 | 导出版本化能力；内部辅助函数保持普通 JS 模块函数 |
| 领域契约 | 时间区间、成绩、查询条件、错误和副作用 | 数据含义不能由显示模板名或任意 JSON 代替 |
| 原生模板 | 按钮、条件选择、时间轴、表格、嵌入网页容器 | 固定布局和可访问性；显示脚本提供的名称与选项 |

已有 `capabilities` 函数表继续作为可调用入口。不增加字符串 eval、任意函数名调用或另一套 action 通道。按钮触发器绑定同包已声明能力、版本化参数和批准 digest；请求类型由宿主认可的契约裁定，不能由脚本自行把控制标成查询。默认不含计时器、启动触发器或后台触发器。ADR-046 的一次命令后查询、未知态和禁止自动重放不变。

“全局凭据变量”采用**每次执行的命名空间访问对象**：模块可以保存 `const authAddress = { namespace: 'school.auth' }`，通过当前 `ctx.credentials` 取值。不得在跨 Profile 的进程全局变量、长寿命 isolate 或 UI 单例缓存秘密。可在一次调用内复用读取结果；跨调用持久化走凭据端口。默认 namespace 为稳定 scriptId，显式同校共享仍可寻址；namespace 不是权限沙箱。更新、退出和切身份后旧对象失效。

## 2. 查询条件与按钮

核心提供中性的单选、多选、文本、日期、时段和触发按钮模板；“空白”指核心不硬编码学校含义，不是向用户呈现无标签按钮。脚本提供稳定 controlId、纯文本/翻译键标签、选项 id/标签、默认值及依赖关系。选项显示内容不作为参数或函数名。

下个 SDK 切片引入有界 `query.controls` 元数据和领域输入新版本：

- 控件限定 `select / multiSelect / text / date / timeRange`；数量、文本长度、选项数及值类型有限制，不接受 HTML、脚本表达式或 Widget tree。
- 每组控件绑定同来源的**只读领域查询**，元数据本身无副作用；来源必须具有该能力。输入的 `filters` 是按 controlId 寻址的有界类型值，不是任意 capability/URL/body 透传。领域通用日期、学期与时段仍有标准字段。
- 脚本验证选项与组合并解释学校含义；宿主验证类型/大小/声明，核心只渲染和传值。结果返回实际生效条件、来源、分页完整性；仅针对已加载结果的本地筛选必须明确范围，不能声称查遍学校。
- 缓存键包含规范化条件、语言、身份及 digest；条件改变取消旧查询，迟到结果不能覆盖新条件。依赖选项重新加载时清除无效选择；数据或网络失败不改成“没有成绩/没有空教室”。
- 通用触发器单独声明 `press → capability + params`；查询选择变化不运行命令，命令不能进入预加载、自动恢复重试或缓存重放。

首片复用已有 `term.list` 的脚本学期名与 id、教室楼栋/节次目录；通用控件协议未实施时，不把 UI 中的临时硬编码筛选声称为新 SDK。

## 3. 空教室与成绩语义

空教室按 ADR-067 返回明确空闲/占用/未知区间及可选来源原因；“无排课”不保证楼门开放、允许进入或没有临时占用。查询一个时段要求整段被已知空闲区间覆盖，半开区间 `[startAt,endAt)` 的缺口保留未知。全部教室共享时间尺度和同一 `now`；当前线每分钟更新，只有数据的原始更新时间决定过期。显示当前时间与时区，日期切换不能把今天的线画到别日。

成绩按学校提供的学期、类型、课程等条件查询；跨学期结果必须在新契约中带逐条学期身份和覆盖范围。旧 `grades.list` 的顶层 term 不能偷偷改成“所有学期”。GPA 与筛选结果区分：官方汇总沿其原范围，本机计算注明仅已加载且满足计算条件的条目；未加载页不参与完整性宣称。

## 4. 登录方式声明与恢复状态机

账号声明扩展为可选 `savedPassword / interactiveWeb / silentWeb` 支持及优先顺序，实际参数名随下一版 SDK 落地冻结。脚本不声明则不得自动尝试；旧包保持当前可见网页登录。保存账号密码是首选登录方式，用户可选择是否保留；临时密码只用于当次输入，保存进当前 Profile/学校的 H/S/M 后端。保存后仍须登录成功且完成真实服务探测，才可显示 authenticated。提供更新保存凭据与删除保存凭据入口；删除密码不自动伪装为退出所有源站会话。

恢复顺序：

1. 业务成功直接返回。取消、网络失败、数据格式变化、合法无权限、限流均保持原错误；脚本必须用学校协议证据判定认证失效，不能把任意非法数值当作密码错误。
2. 确认子票据失效时，优先用母票据换签一次，再验证目标服务；失败但尚不能确认母票据失效时返回 unknown，不循环尝试。
3. 母票据已失效且无保存密码时返回需要交互登录；不会自动弹出浏览器或后台收集输入。
4. 有保存密码、脚本声明 silentWeb 且当前策略允许时，尝试一次受限隐藏 WebView 登录；探测成功后才发布新票据。验证码/MFA 转为 interactionRequired；明确密码拒绝转为 credentialsRejected；学校明确禁用账户才可标 accountDisabled。
5. 超时或网络错误保留 unknown，但本次自动密码尝试额度已消耗。静默失败后设置持久恢复阻断，普通刷新、并发请求、进程重启不能再次自动尝试；只有用户更新密码或明确手动重试才解除。不能把“失败”直接展示为“密码已更改/账户已禁用”。

会话按 Profile/学校/账号 namespace/凭据修订/批准来源合并恢复任务，切身份撤销。密码恢复额度属于凭据修订，不属于按钮次数。新凭据先验证再替换；持久化失败不宣告成功。只读业务最多在成功恢复后重查一次；签到、发送、控制、填表提交等副作用永不由恢复自动重放。

**需要通知核心**：新增结构化账号事件，至少含声明 accountId、状态、固定 reason、可采取操作；宿主附加来源、代际及时间，脚本不能伪造其他来源。中间 renewing 可作瞬时进度；最终状态沿用 authenticated/signedOut/expired/unknown，interactionRequired/credentialsRejected/accountDisabled 是原因，不无限增殖账号状态。事件不带密码、Cookie、响应正文、任意异常堆栈；核心据事件更新账号入口和待登录提示。业务错误照常结束，不用全局事件吞掉调用错误。SDK 12 先沿用 `authentication_required` 与 `account.session`，不能声称已经存在新事件 API。

## 5. 网页模板与 DOM

补充固定 `webContent` 模板作为原生页面中的网页区域，用于填表等标准数据模板难以覆盖的业务。宿主拥有标题、来源/域名、关闭、加载/失败状态和返回导航；脚本决定初始 URL、已声明资源与 DOM 操作。禁止用网页覆盖安装授权、核心账号权限提示或整个宿主导航。

区分三种用途：可见业务网页、可见登录 fallback、隐藏认证恢复。分别声明、分别限时；隐藏会话只能运行认证用途，不自动提交业务表单。网页内容可由受信包内 HTML/资源构建，也可来自学校远端；本地内容使用独立受限 origin，不用具有文件权限的 file:// 页面。DOM 可自由编辑当前授权文档，但仍只能访问声明网络，跳转/iframe/子资源/WebSocket/下载均受宿主检查。

远端网页不能取得 QuickJS ctx、凭据库或通用能力桥。桥只提供绑定当前文档和一次 nonce 的有界结果；页面消息视为不可信数据。Cookie 存储沿浏览器独占租约，在退出、切身份、取消和异常关闭时清理；本地 DOM 不得跨身份持久化秘密。HTTPS、来源检查、系统权限和 APPTunnel 传输边界不能因嵌入/隐藏而放松。APPTunnel 尚未覆盖 WebView 时继续明确拒绝，不能静默直连。

提交由用户在页面内明确触发；发生连接中断显示提交结果未知，不自动重发。学校页面有验证码/MFA/文件选择时恢复可见交互；未授权原生输入仍拒绝。实现需先把现有 ScriptBrowserBridge 的控制逻辑与页面布局分离，统一可见/嵌入/隐藏三个 presenter，避免复制网络策略。

## 6. 核心与脚本国际化

核心增加 `uz`（乌兹别克语，首选拉丁字母）、`ru`（俄语）、`fa`（波斯语）；不凭语言名单声称留学生人数排序。核心 ARB 覆盖全部 UI、错误和无障碍标签，保留 zh/en。波斯语验证 RTL、混排标识符、时间轴方向、数字与日期格式；界面语言不隐式更改学校时区、成绩数值、学期 id 或协议参数。

脚本随包携带本地语言资源，作者自行选择适配语言，资源字节纳入授权 digest，安装时校验并保存。具体格式由 ADR-070 细化为 `localization.defaultLocale/messages`，支持语言从字典键派生，不重复声明数组。安装不从学校任意动态下载翻译。匹配按精确标签→语言加文字系统→基础语言→包默认语言回退，缺词条使用默认字典；不能把中文复制到新语言文件当成已翻译。

宿主向调用传递 locale 与包内翻译访问端口；纯 UI 字符串使用稳定 key，学校原始内容按其契约保留，不自动翻译成绩课程名、密码、学号或私密响应。标签不参与实体 id、缓存身份与控制判断；可缓存的语言相关结果按 locale 分开。SDK13 已提供这些资源接口，旧包继续原文本。

## 7. 版本、迁移与验证

下一 SDK 切片必须一起更新 package schema、Dart manifest/SDK、运行时桥、打包器、安装说明、生成物与负例；包更新重新批准。查询/账号/网页各领域独立升级 schema，不以一次大版本暗中改变旧字段。旧 V1 登录和命令门继续隔离；不存在新源码事件替换旧 Broker 的推论。

验收覆盖：失效层级矩阵、并发恢复合并、一次静默额度/重启阻断、取消与 late event、保存失败、坏密码/MFA/禁用证据、控制不重放；网页导航/iframe/子资源/TLS/隧道拒绝、关闭清理、填表未知态；筛选未知值/分页/语言/digest 变化；三种语言完整性和 fa RTL。合成测试、真机 UI、真实学校/网关与人工安全审阅分别记录，不互相替代。

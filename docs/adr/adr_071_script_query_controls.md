# ADR-071 · 脚本定义的只读查询条件

- 日期：2026-11-03
- 状态：Accepted（所有者授权继续实施 ADR-068 的后续切片）
- 承接：ADR-041、046、066、068、070。

## 决定与范围

新增 `query.controls` 1.0，输入仅 `target`，限 `grades.list` 和 `classroom.available`。输出相同 target、纯文本 title/submitLabel、最多8个控件。核心提供 select、text、date、timeRange 固定模板，脚本决定标签、可选值和默认值。不是 Widget tree，也不提供任意函数、URL或命令绑定。

首片直接绑定已有标准输入，不改写旧输入契约：成绩只允许 term；教室允许 date/room，timeRange 一次绑定 start/end。核心验证 target、控件类型/参数匹配、唯一控件id与唯一参数、选项唯一、日期真实存在、时间为 HH:mm、start<end 且同一日。两端均留空时省略时段，只填一端则拒绝；不假设跨午夜。text 的空值表示删除可选条件，date 必须填写有效日期，select 必须选中声明值。条件组合及学校业务合法性仍由脚本验证。

控件来自目标查询的同包已批准 digest，不能按 query.controls 的全局覆盖来源另选包。元数据读取是无交互只读请求：不弹登录/扫码，不持久缓存、不预加载。查询条件只在用户点击脚本给出的提交按钮后原子应用；取消保持原条件。元数据失败保留当前结果并显示错误，不伪造空选项，也不静默使用旧元数据。

应用条件后的查询固定沿当前卡片原来源；账号、来源、语言或批准代际变化使对话框的迟到结果失效。条件进入现有查询缓存参数；不通过隐藏字段传脚本代码或网络参数。新请求沿已有会话取消/身份门执行；控件本身不发送控制、签到、消息或表单。

## 迁移

旧包未声明 query.controls 时保留成绩学期选择与教室日期等既有输入。新包显式声明能力并重新批准；query.controls 为领域能力1.0，不要求把旧 grades.list/classroom.available 参数字段改义或把该能力当作新授权。支持语言由 SDK13 包资源决定，脚本使用 ctx.i18n.t 生成标签；没有国际化声明的包仍返回原有文本。

后续多选、任意学校条件 filters、依赖条件、跨午夜或其他业务目标需另行补充明确领域参数版本，不能借本切片的标准参数白名单夹带。

## 验证

合成与真实 QuickJS 覆盖脚本选项和未知target拒绝；原生验证输入类型/重复绑定/未知选项/越界/日期时段、同来源、取消和身份变更、旧包fallback。学校真实查询和人工核心审阅另记。

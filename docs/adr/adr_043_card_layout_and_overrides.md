# ADR-043 同名能力覆盖与可编辑首页卡片

- **Decision**：Accepted（2026-10-31，所有者同意同名覆盖、有限卡片选择，并要求落地长按编辑和拉伸尺寸）。
- **Landing**：客户端首片已实现并通过下述自动回归；真机手势及核心人工安全审阅仍待完成。
- **范围**：ADR-042 的首次客户端切片；其公共中继、匿名权限 profile、论坛/馆藏领域模型仍待实施。

## 1. 同名入口覆盖

学校包继续导出 `capabilities[name]`，主包无需感知增强包。宿主选择同名入口的实现，各包仍在自己的执行上下文中运行，不合并 JS 全局、闭包或凭据权限。只覆盖已声明且参数/结果语义兼容的公开能力，不替换主包私有函数。

保留逐能力的稳定默认来源，增强覆盖由用户明确启用；多个候选可显式选择。更新既有包不能因安装顺序变动抢占来源；禁用或卸载覆盖包恢复原可用来源。首次迁移保存旧注册表实际选源。没有覆盖才使用基础来源；执行失败不等于入口缺失，不自动吞错重试，更不重放命令。预加载只执行有效来源，安装内容授权、命令专门确认、取消与输出校验保持原有边界。SDK 2 namespace 仍非权限隔离。

## 2. 有限卡片与尺寸

2026-11-01 交互修订（所有者要求）：客户端本地布局提供 compact（图标与名称入口）、regular（半宽摘要按钮）、expanded（全宽详细卡片）三档。所有业务卡都支持三档：小尺寸点击后在原位置临时展开完整操作，再收起回到已保存偏好；同一有状态组件保持挂载，切尺寸不丢选择、查询结果或认证状态。半宽优先展示关键值、最新记录或查询状态，全宽保留表单、来源、时间及详细预览；命令仍走原有确认入口。

采用四列流式网格，图标/半宽/全宽分别占 1/2/4 列；窄屏或大字号时半宽可回到全行，不写回偏好。高度按内容测量。没有卡片外部大边框、拖把或缩放框。长按一次直接拾起卡片，悬停时邻项动画让位，边缘自动滚动，松手保存；取消或移出有效区域回到原顺序。编辑态点卡片打开尺寸和移动菜单，作为触摸、键盘及辅助功能的替代入口。编辑态屏蔽业务动作，完成后恢复。

本地布局格式显式升级为 v2：旧 v1 compact（少量摘要）迁到 regular，旧 regular/expanded 迁到 expanded，顺序不变。SDK 6 manifest 的枚举和含义保持不变，旧 compact 建议映射到本地 regular，旧 regular/expanded 建议映射到 expanded；本轮不扩充脚本声明范围。用户本地偏好始终优先。

布局按学校及稳定业务卡片 ID 保存，存储只含顺序和呈现偏好，不含业务数据/凭据。不同学校不串布局；来源覆盖、包版本更新、刷新数据不会重置布局。暂时不可用的卡片保留偏好，重新出现时恢复。读取失败回默认；异步读取不得覆盖用户已开始的编辑，旧学校的迟到操作不得覆盖新学校。

### 2.1 用户展示配置补充（2026-11-01，所有者测试后要求）

最小档的整格都是按钮，以可用逻辑宽度扣除间距后的四分之一为常规宽度；显示图标与名称，最小高度 104dp，名称随字号增高。物理像素由 Flutter 的设备缩放处理，不用 DPI 数值作为宽度。窄屏保留现有两列降级。

提供常驻“主页展示”入口，列出本校当前可用卡片，用户可逐项显示/隐藏，也可全部隐藏并从相同入口恢复。隐藏保留顺序、尺寸和样式；新出现的卡片默认显示，暂时不可用的卡片保留偏好。隐藏是首页呈现设置，不等于禁用能力、清除数据或停止会话缓存刷新。隐藏的卡片从布局移除，重新显示可重建业务组件；单纯切尺寸与临时展开仍保持原组件状态。

本地格式升级为 v3，在 v2 的 order/sizes 上加入 hidden（卡片 ID 列表）和 presets（卡片 ID 到宿主样式 ID 的映射）。v1 继续按上述规则迁移尺寸，v1/v2 默认全部显示并采用 standard 样式。存储不包含业务查询条件、数据或提供者 ID。

展示样式与尺寸独立。客户端每个 HomeCardEntry 可登记有限的样式 ID/本地化名称，HomeCardPresentation 将有效样式传入原有业务组件；组件用同一查询状态和数据实现样式。standard 始终可用，未登记的样式回退 standard 并保留偏好，以适应应用版本变化。仅在卡片登记了额外样式时显示选择器。本轮预留注册、选择、存储、回退链路；课程预览、下一次考试等具体模型后续实现，不提前向用户列出不可用选项，也不新增 SDK/manifest 字段。

## 3. 脚本建议与 SDK

新增 SDK 6 的可选静态 `cards` 展示声明，包含已知业务 `type` 与 `defaultVariant`；稳定卡片 ID 由客户端业务类型确定。没有声明完全保持旧包行为；用户偏好优先于包建议，建议优先于客户端默认。声明不是布局代码，不接受 Widget tree、像素尺寸、颜色、任意事件或请求地址。

旧宿主拒绝未知 SDK；新宿主继续保留 SDK 1–5 行为。新声明同源码、网络与其他 manifest 一起绑定安装 digest。实现 schema、Dart parser、TS 包校验、SDK 声明和回归时保持一致。`home` 仍是查询/缓存策略，`cards` 只表达展示建议，不能通过它声明未提供的业务能力或绕过命令入口。

同名覆盖默认继承用户布局；启用增强包不要求重写主包展示声明。公共匿名增强的低权限能力裁剪另行实施，不能因存在 cards 或覆盖入口就宣称隔离已实现。

## 4. 验证

覆盖长按编辑、按钮及拖动换序、三档切换与临时展开、屏幕/大字号变化、编辑态不触发业务按钮、刷新不丢布局、重建/重启持久化、学校隔离、损坏设置、保存失败与异步竞态。有限形式需验证数据可读、剩余内容可访问，实际首页接线不能仅测试一个空壳。

覆盖来源固定、更新不抢占、禁用恢复、未选包不预加载、旧存储迁移、manifest 建议的 SDK/枚举/能力校验和旧包回归。核心来源选择仍需人工实质审阅，自动测试不替代真机手势验收。

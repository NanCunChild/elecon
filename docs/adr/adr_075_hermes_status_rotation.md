# ADR-075 · Hermes 状态检查的受保护会话轮换

- 日期：2026-11-03
- 状态：Accepted（按继续实现授权；不替代真实网关与人工网络审阅）
- 承接：ADR-062、064、066。

## 问题与决定

网关的只读 authConfig / onlineInfo 也可能 Set-Cookie 轮换 SID。只返回 authenticated 而丢弃最新 Cookie 会让下一调用使用旧材料。宿主检查成功后，由固定原生桥返回同一已验证身份的会话快照，核心在当前 Profile/学校/执行代际及原记录修订仍一致时原子持久化，再返回认证状态。状态页面和学校脚本仅收到固定状态、账号标签与时间，永远不收到快照。

快照保持 device/connection/signing material 与身份，SID 和 Cookie 以最后一条控制面响应后的 Cookie jar 为准。缺失、删除或非法 SID 不能恢复旧 SID；只读检查返回 unknown，不保存，也不自动提交密码。显式失效证据仍返回 expired。持久化失败、来源或身份变化、并发替换不得发布成功，旧记录按当前撤销规则回滚。执行中的 native TCP 已读取最新 Cookie，这个切片补状态检查跨调用保存，不改变 TCP 模式或请求签名。

## 兼容与范围

native C ABI 的 checkSession 成功结果新增仅宿主可见的 session。旧测试替身/旧 native 未返回快照时保持原有状态行为；新版 native 遇到非法快照返回 unknown。配置序列化版本仍为 1，字段含义不变。轮换不重新选择网络、不撤销当前只读调用、不重放任何业务请求。

此切片不是长期自动续期：资源轮询跨调用发布、控制面 antiMITM 协商与多种 TCP 版本仍分别需要实施。测试覆盖合成 Cookie 轮换/删除、后续检查读取新值、状态不泄露秘密、重启恢复、保存失败和迟到结果。

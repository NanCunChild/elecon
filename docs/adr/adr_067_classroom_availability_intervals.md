# ADR-067 · 空教室精确时段与统一时间轴

- 日期：2026-11-03
- 状态：Accepted（所有者授权空闲时间、原因、当前时间线与时段筛选；实现待验收）
- 承接：ADR-041、047、066；脚本定义通用查询条件另见 ADR-068。

## 决定

`classroom.available` 输出升至 1.2，增加可选 `items[].intervals`，每项包含 RFC3339 绝对时刻 `startAt`、`endAt`、`status`（available/occupied/unknown），以及可选纯文本 `reason`。区间采用左闭右开，结束必须晚于开始；同一教室的区间不得重叠。缺少覆盖、非法或重叠数据为未知，不推导为空闲；原因缺失显示“未提供原因”。原 `sections` 及聚合 `occupied/status` 含义不变。

脚本负责学校时区、课表时段和占用协议的归一。西电只有节次占用证据，因此仅为已知节次生成区间：无占用记录不代表教学楼开放，也不证明课间、午休或夜间可用；不得自动填满节间空白。未查询日历日时保留原节次输出，不捏造绝对日期。当前已有参数 1.1 仍保持节次窗口语义；新版精确整段筛选在已取回的绝对区间上执行，不悄悄改变旧参数含义。

原生模板提供统一横轴、所有教室共用的当前时间线、设备当前时间显示及起止时间选择。时刻统一换算为设备本地时间并明确标注，避免设备出国/跨时区时把学校墙钟误当本地时间。学校原有 date/timeZone 元信息仍保留。选中区间只有被 available 区间连续完整覆盖且无冲突时才匹配；占用、未知、缺口都不匹配。切换来源、身份、楼栋或日期不保留旧筛选结果。计时器只重绘时间线，不自动发学校请求。

## 版本与回滚

保存 1.1 精确 schema 快照，registry 同时接受 1.1/1.2；生成 TS/Dart 类型与运行时输出 validator。旧包继续使用 1.1；新包更新声明 1.2 并重新安装批准。旧宿主明确拒绝未知版本。回滚学校包和宿主时按批准 digest 恢复，不重新解释旧缓存。输入契约仍为 1.1，无新增权限、网络请求或依赖。

## 验证

合成学校数据覆盖节次区间、缺字段、课间未知与原因；客户端验证精确全覆盖、首尾边界、重叠冲突、统一当前线、旧结果无区间与过滤空态。相关模块/Widget/生成物检查与真实学校数据验收分别记录。脚本定义的通用条件按钮由后续 ADR-068 承接，不把固定 UI 控件称作已完成的任意脚本触发器。

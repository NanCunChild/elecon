# ADR-091 · 查询表单缓存与可选条件

- 日期：2026-11-05
- 状态：Accepted（用户授权按校园体验研究落地；核心存储实现仍需人工审阅后合并）
- 承接：ADR-038、082、083、086；不新增 SDK 或脚本权限。

## 决定

表单定义、延迟选项与未提交草稿使用独立的受保护缓存，不写业务结果缓存。地址包含学校、包 ID、批准 digest、目标能力、表单版本、语言，以及规范化请求参数；Profile 由其独立凭据后端隔离。仅宿主可访问保留地址，UI 只取得表单数据，M 档继续只存内存。

基础定义与延迟选项最长复用 15 分钟，原始取得时间不因读取改变；单条至多 128 KiB，每校至多 64 条/1 MiB，草稿保留七天。延迟请求按指定字段和依赖值分别缓存，改变依赖不能复用旧选项。过期选项不得验证已有选择；恢复该选择后重新加载，失败时显示待确认并允许清除。元数据损坏或存储失败可重新获取，不据此授予提交权限。

学校仍决定日期与时间默认值。含未由用户选择的 date/timeRange 默认值的基础表单，每次打开重新请求脚本，不能缓存冻结昨日默认值；已选值及动态依赖作为完整请求指纹。西电基础表单离线生成，因此重新解析学校默认日期不访问网络。宿主不猜学校时区、不按字段名识别西电业务。

草稿仅保存用户编辑及显式清除的字段，并记录编辑所基于的已应用值。脚本默认值不自动成为用户编辑；已应用值变化时丢弃不匹配草稿。离页保留草稿，明确取消/重置恢复已应用条件，提交后清除草稿。恢复草稿不得触发初始业务查询。元数据、草稿和结果分别保存，任何草稿写入都不执行学校业务。

未完成的数字输入及时间区间使用草稿专用 `rawEditors` 文本表，最多 64 项；键仅为字段 ID 或 `range:<id>:start/end`，数字输入最多 64 字符，时间边至多 5 字符。恢复时依据最新字段类型重建编辑器和非法/不完整状态，不能回填脚本默认值掩盖未完成输入。原始文本不进入 `filters`、元数据请求或业务提交；必须通过现有字段校验后才产生有类型的值。旧草稿未含此可选表时按原格式读取，损坏或超界草稿丢弃。

身份、登录、退出、来源禁用/更新、语言变化使在途响应失效。显式账号登录必须将同校表单缓存与业务缓存一并持久清除，失败则不执行登录；不能只靠内存代际跨重启隔离。保存前后校验当前绑定，旧响应不得写入新身份。沿用 H/S/M 后端及原有持久化失败处理，不启用新存储模式。

## 条件展示与迁移

沿已有 required 语义：必填常显，可选折叠。折叠区显示当前有效条件数量及摘要；已有可选值仍校验，无值的延迟字段只在展开后加载。表单定义/依赖刷新不隐式展开条件，也不删除用户可见的已应用条件。

西电新包移除 campus 控件与依赖，楼栋包含完整南北目录，默认只提供学校日期，不预填时间段。新版 filters 明确拒绝 campus，避免无声忽略旧调用者的条件；旧顶层 campus 继续作为兼容条件显式核验。更新更换 digest，原表单/结果缓存自然失效。仍是单栋查询，不声称全校覆盖。

## 验证与回滚

覆盖依赖缓存、原始时间/过期、学校/来源/语言/版本隔离、持久重启、草稿/默认值区别、恢复不执行查询、身份变化/登录清理失败，以及可选项折叠时的加载与提交。学校合成测试覆盖南北楼栋、无隐藏时段、旧 campus 明确拒绝与兼容顶层条件。回滚客户端时忽略保留类型，学校回滚按正常 digest 重新授权；缓存不成为执行授权。

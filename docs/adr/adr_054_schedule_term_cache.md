# ADR-054 整学期课表缓存与非阻塞刷新

- **Decision**：Accepted（2026-11-02，所有者要求切周复用缓存、过期后台刷新且不影响查看）。
- **Landing**：1.2 契约、学校 0.19.0、整学期缓存投影和原生页后台刷新已实现；自动回归通过，更新包的真机验证及人工核心审阅另行记录。
- **承接**：ADR-038/047/048/053。保持身份、学校、来源及批准 digest 的缓存隔离。

## 数据与版本

`schedule.week` 1.2 保持 `days` 表示所选周，新增可选 `termWeeks`，包含同次获取的整学期各周详情及其明确日期范围；只对枚举出的周声明完整结果，空 days 表示该周无课，未枚举的周仍为未知。不从课程 weeks 或预览数量推断未提供的课程，不无声扩大 1.1 的字段含义。保留 1.0/1.1 校验；新学校包声明 1.2 并经内容确认升级。西电同一次整学期接口结果同时生成周详情、预览与 termWeeks，不逐周请求源站。

宿主对明确的 week/term 查询可从同身份、同来源 digest、同学期的有效缓存投影对应周；保留原始取得时间、TTL 和保留期限，不为本地切周创建新的刷新时间。额外筛选参数不得被忽略。首页无参当前周查询继续独立，不能被用户最后浏览的历史周覆盖。

## 查看与刷新

详情先读缓存，命中后立即展示；在新鲜期内切周不运行脚本或请求源站。过期数据仍可查看和切周，由一个去重的非交互请求刷新。刷新不弹登录、不清空已有网格、不禁用周选择；失败保留旧值及时间提示，显式刷新/登录入口仍可用。无缓存的周保留明确加载/错误，不将其他周的课程冒充目标周。晚到结果不得把用户拉回发起请求时的周。

来源、Profile、学校或授权变化撤销在途结果并清除页面数据。旧 1.0/1.1 来源沿用逐周缓存，未提供完整周详情时才取数。缓存容量与保留期沿 ADR-038，不持久化到公共缓存。

## 验证

版本正负例与代码生成；整学期解析包含空周、调课、跨周和日期；真实 QuickJS 输出；新鲜缓存切周零请求、过期后台刷新去重、离线仍可切周、刷新晚到不回退选择、首页与历史周分离、身份与批准 digest 隔离。自动测试与授权设备观察分别记录。

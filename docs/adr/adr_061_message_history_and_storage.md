# ADR-061 · 会话、历史消息与核心 SQLite 存储

- 日期：2026-11-02
- 状态：Accepted（所有者要求完善超星聊天、历史与 SQLite 适配；核心/网络实现须人工实质审阅后合并）
- 承接：ADR-044、046、052、053；只替代 ADR-052 对新增消息能力的“不持久化”限制。

## 职责与契约

脚本负责服务登录、群/联系人发现、历史游标、协议解码与一次文本发送。核心负责原生会话/聊天页面、发送状态和本地 SQLite 存储；不提供 SQL、文件路径或数据库句柄给脚本。作业、课程、任务、签到及附件仅显示有界纯文本摘要，不下发 URL 跳转或操作。业务详情与这些实体的责任另行决定。

新增 `messages.conversations`、`messages.history`、`messages.send` 1.0；保留 `messages.list` 1.0 的短时群窗口语义。新增请求显式绑定当前服务 accountId；历史与发送同时绑定 conversationId 和 group/direct 类型，同名 ID 不合并。结果包含 serviceId/accountId/fetchedAt；历史只有当前源站页，按稳定消息 ID 去重、时间排序，保留 nextCursor/hasMore，未知不能伪装为完整。撤回 ID 是墓碑，先收到撤回再补到旧页也不能恢复正文。协议回执不混进聊天正文，不猜未读数，不因查看自动标记已读。

发送由明确按钮触发普通前台请求，使用客户端请求 ID 对应服务确认；仅纯文本，每次至多发送一次。只有匹配的服务器确认可显示已发送；服务拒绝、未发送失败和发送后结果未知分开处理。超时/取消/失去确认不能自动重发；没有持久发件箱与后台重试。成功确认后可以只读刷新历史。

全部新增能力禁止 home/preload/后台请求。会话发现优先使用 conversations，旧包仍使用 list。详情、分页与账号操作固定到同一个批准包，不跨来源查询。更新重新授权新增的 Easemob REST origin；Cookie 仍由超星脚本保管，IM token 只发送固定受限 REST/WebSocket 端点。

## 本地数据与生命周期

核心 SQLite 首片采用有界内存 VFS 数据库快照，SQL 在背景 isolate 执行；提交后快照进入当前 Profile 的 H/S/M 受保护存储，不生成明文数据库/WAL/临时文件。使用 pub.dev `sqlite3` 3.3.4（MIT，https://pub.dev/packages/sqlite3/versions/3.3.4）；SQLite 本体为 public domain。沿用已有保护档位，M 档只驻留内存，不因引入 SQLite 静默降级为明文持久化。

每个 Profile 内按学校、包 ID、批准 digest、serviceId、accountId 分库；会话类型与 ID、消息 ID 为库内键。宿主保存最近一次成功验证的账号标识，离线读取只使用该标识、当前启用/批准来源和同一存储后端，不能由 UI 任意指定另一账号。认证失效、显式退出/重新登录、卸载/禁用/更新来源清除相应记录；学校退出清除该学校；切 Profile/学校/来源取消在途读取、页面及草稿。提交前再次校验身份、安装代际和取消，晚到结果不落入新身份。

只保存规范化数据，限每来源/账号 4 MiB、最多 2000 条消息、500 个会话；按本地取得时间保留 30 天。正文、分页状态、会话标题都在保护层内；诊断不记录正文或请求参数。SQLite 是本地已加载记录，不代表完整远端归档；本地分页与远端历史分页分别展示，读取失败保留已加载记录及原始取得时间。持久化失败不能把远端已确认发送改成可自动重试的失败。存储格式独立版本化，未知版本拒读；旧窗口无数据需要迁移。

## 协议参考与验证

Quasar-core 仅核对端点、protobuf 字段及历史/撤回/回执协议事实；遵循 ADR-052 的许可边界，不引入或翻译 GPL Go 实现/生成物。合成夹具覆盖大整数 ID/游标、群与私聊、重叠页、非法/循环游标、撤回乱序、非文本摘要、错误身份、一次发送和未知结果。实际打包脚本通过 QuickJS 桥接验证；SQLite 验证恢复、隔离、去重、分页、撤回、过期/容量和写入失败；页面验证离页取消、离线阅读和不可点击业务消息。

回滚可卸载新版增强包并恢复旧窗口；新增存储可清除，不迁移旧凭据地址。自动回归、真实账号/真机和人工审阅分别记录，不将协议合成测试作为学校验收。

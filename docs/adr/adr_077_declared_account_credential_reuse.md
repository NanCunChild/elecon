# ADR-077 · 脚本声明的同校账号凭据复用

- 日期：2026-11-03
- 状态：Accepted（所有者要求脚本指定 IDS 等凭据复用并承担目标检测；真实学校与人工审阅独立验收）
- 承接：ADR-064、066、072。

SDK15 账号可声明 `credentialReuse: {sourceAccountId, service, gatewayUrl, loginDomain}`。源必须是同包另一已声明保存密码账号，目标必须有同包显式登录及只读状态绑定；首片 service 固定为 `hermes-atrust`。gatewayUrl 是没有路径、查询或片段的 HTTPS origin，必须精确属于批准包的 network.origins。loginDomain 必填，空字符串沿用 Hermes 唯一密码域规则。目标不能同时声明自己的保存密码认证，不允许链式复用。旧 SDK 拒绝新字段；修改声明需要新包版本及重新批准。

脚本仅在用户显式进入目标账号登录时调用 `ctx.appTunnel.login('hermes-atrust', {accountId: 'vpn'})`。宿主重核当前 Profile、学校、批准 digest、目标登录能力/参数、源凭据修订与取消代际，直接把源密码交给固定 Hermes 服务；脚本及 UI 不通过此接口取得密码。一次执行最多一次登录，无后台复用、自动密码重试或业务请求重放。源账号没有保存密码时返回固定 authentication_required，不推断目标已登录。

认证执行一次密码提交及源站校验，再执行目标服务只读状态检查；仅已验证身份与合法会话可原子保存。只保存目标会话，不复制或修改源密码，不创建独立 Hermes 密码记录。失败、取消、网络未知、MFA、密码拒绝均不改变源账号状态。脚本负责判断学校服务是否使用同一身份、选择何时复用、检查返回的目标状态以及后续业务可用性，不能以 IDS 成功推断 VPN 成功。核心负责授权、存储、固定原生服务与状态展示，不内置学校共享账号关系。

没有真实学校关系与网关证据时，仅提供合成模板，不为生产学校包猜测关系。验证覆盖旧 SDK 拒绝、坏引用/网关拒绝、非登录/后台拒绝、单次性、源修订与取消、验证失败不保存、成功只持久目标会话。自动测试不替代真实学校与人工凭据/网络审阅。

目标只读状态同时匹配声明的网关与非空认证域；当前学校保存的其它网关/域会话返回 signedOut，不触发网络检查，不能被借用为本目标的成功证据。

首片 Hermes 控制面暂不接受脚本 IP/CIDR 规则，因此含 `network.ipAllow` 的包禁止声明凭据复用；需要该约束时应等待固定控制面实现。不能静默忽略包的 IP 限制。

# ADR-080 · 受信脚本扩展、长期网页会话与认证挑战

- 日期：2026-11-04
- 状态：Accepted（所有者要求减少受信脚本限制，支持长期 WebView JS、自动操作、全部能力首页入口与验证码/MFA；本次接受方向，接口与实现待分片落地）
- 承接并局部修订：ADR-034、041、043、046、056、068、072、073。
- 实施入口：[功能补充切片](../planning/feature_supplements.md#受信脚本扩展adr-080)。本文不分配 SDK 版本、不新增可用 manifest 字段。

## 1. 核心提供跨学校的共性基底

学校脚本按用户安装的受信扩展设计。学校协议、认证步骤、网页增强、交互细节和自动化策略尽量由脚本实现；核心提供可组合的执行、浏览器、调度、认证输入、存储、网络及展示设施。新增学校行为应优先通过组合这些设施实现，避免每个学校按钮或认证分支都修改核心。

原生页面继续承载共性业务与统一交互；网页是可编程的扩展面，可以用 HTML/CSS/JS、DOM、SVG、Canvas 绘制框图、按钮和复杂界面。长期附加脚本、事件监听、观察 DOM、跨页面重新注入和自动点击是正式目标，不再将“只能固定 DOM 操作”“必须真实用户点击每个按钮”“只能短请求”作为永久架构限制。不下发 Flutter Widget tree 不等于禁止脚本自绘网页。

保留的基础边界是批准执行字节、当前授权 Profile/学校身份、声明网络范围、受保护存储、可撤销执行以及宿主进程稳定性。原生设备能力通过宿主端口提供；本决定不开放任意文件、进程、FFI 或原生模块侧载，不改变公网零凭据和 V1 兼容路径。同校受信扩展不是相互隔离的最小权限沙箱。

## 2. 长期 WebView 会话与网页 JS

新增独立的网页会话生命周期。短业务请求完成后，可以保留用户打开的网页与附加程序；不能只把现有请求超时改成无限大。宿主负责创建、挂接、前后台状态、恢复、关闭和撤销，脚本负责网页逻辑。JS 可长期响应事件，多模块和资源按包组织，不为每个按钮往返一次 QuickJS。

包内 JS、HTML、CSS 和依赖资源均属于执行授权内容；后续包格式明确资源清单、大小与 digest。允许将较大的第三方绘图库随包发布，来源和许可证按依赖规则记录；资源额度按实际负载测量调整，不把 ADR-073 的首片小模板预算固化为长期上限。远端学校文档及其站点脚本属于声明网站的内容，不能宣称其字节已由包 digest 批准；下载远端代码成为宿主受信扩展须经过代码安装/更新流程。

至少区分两个上下文：包内受信网页与附加程序、远端站点页面。包内扩展可通过来源绑定的消息桥组合宿主能力；远端 DOM/站点 JS 不能仅因和附加程序同页便取得凭据端口。需要操作远端 DOM 的代码允许在页面上下文运行，但该上下文不得持有可被页面冒用的通用特权桥；特权侧通过平台隔离上下文或经过验证的独立控制通道通信。平台不支持所需隔离时，清楚标注可提供的模式，不虚构隔离保障。

注入策略明确 origin、frame、导航代际、注入时机和重复挂接清理。支持跨导航重挂、事件监听、DOM 构造与程序点击；结束页面时清理监听器、计时器和会话资源。宿主始终提供独立于网页的来源提示、关闭/停止入口；网页不能遮蔽这些控制。

网络范围由浏览器设施兑现，覆盖导航、子资源、fetch/XHR、WebSocket、worker 及其他出网通道；APPTunnel 依赖不能退回直连。当前浏览器尚未具备完整覆盖，因此新模式不能仅删除 CSP 禁脚本策略就宣称完成。包内本地 JS 绘图可先实现，再完成远端增强和隧道支持；现有离线模式继续可用。

长期存在与持续占用 CPU 分开管理：会话存活时间、单次执行 CPU、内存、资源大小、请求速率和并发分别计量。用户可停止异常会话，宿主可中断失控任务；额度应支持合理的大型扩展，不能把短请求的累计调用次数直接套到整日会话。切身份、退出、禁用、撤销和更新终止旧代际，旧回调不能取得新身份或新包授权。

## 3. 自动操作与定时任务

允许用户启用的脚本自动化，包括到点选择课程、填表和点击提交。核心提供通用任务调度与运行记录，学校脚本决定目标课程、准备流程、业务条件和提交协议，不在核心内置选课算法。

用户创建或启用任务时确定目标、身份、时间和重复规则；已启用任务在该范围内执行，无需每次到点再次点击确认。脚本可以提出任务建议，但安装一个包或显示首页卡片本身不等于用户已经启用其中所有计划。计划绑定批准来源及 digest、账号、参数、时区、运行窗口和明确的错过策略；更新不能默默换成新代码执行旧任务。

长期前台网页中的定时器、应用后台任务、进程退出后的系统调度分别描述能力。平台适配提供可用性与运行条件，不能承诺所有平台在锁屏、被终止或离线时精确到点。需要前台网页的任务应说明须保持页面可用；不可用时记录错过/暂停/失败，不伪造已点击或已选课。

任务状态至少区分待执行、运行中、等待交互、成功、失败、取消、错过和结果未知。每次计划发生有独立运行标识，持久化领取/发送状态，阻止并发或重启产生重复提交。发送前重新检查来源、身份和取消；若发送后进程退出而无结果证据，保持未知。客户端去重不等于源站 exactly-once，源站幂等键或状态查询由脚本按协议使用。

本决定扩展 ADR-046 的触发来源：手动按钮和已启用计划都可发起通用请求。主动设定的下一次运行与失败自动重放分别建模；未知提交不自动重发。学校流程确需重试时，脚本说明幂等或已确认未提交的依据，计划显式声明次数、间隔与停止条件；未具备依据时保留未知并交给用户处理。预加载、缓存恢复、首页整体刷新仍不能触发写操作。

后台遇到验证码/MFA 转为等待交互，保留恢复期限；用户回到前台完成挑战后再次检查任务窗口和业务状态。到点不代表可以跳过认证挑战，也不把认证成功视为业务提交成功。

## 4. 所有能力均可绑定首页卡片

取消固定卡片类型与少量能力之间的一一白名单作为扩展边界。任何已声明、可执行能力都可绑定首页入口，包括登录、消息、控制、网页、自动化及后续社区能力；同一能力可有多个固定参数实例。用户决定卡片显隐、顺序与大小，安装或升级不得抢占现有布局和来源。

卡片声明分离身份、标题、来源、参数、展示方式和触发方式。共性数据优先复用原生领域组件；没有专用组件时提供通用入口、输入/结果展示，或打开脚本网页。原生结构化展示继续遵守领域契约，不能把任意 JSON 强塞给已有解码器；网页局部交互无须为每个绘图状态新增全局业务 schema。

显示入口不要求预先调用能力。需要输入的能力先收集输入，写操作只在按钮或已启用计划触发时执行；查询的缓存/自动刷新策略单独声明和裁定。缺输入、缺登录、平台不支持分别展示，不因没有专用原生卡片就禁止能力上首页。

## 5. 独立验证码界面与通用 MFA

核心提供独立于账号密码输入页的认证挑战页面及会话，不再只提供“请去官方网页登录”的单一路径。脚本决定是否需要挑战、展示哪一步、如何获取/刷新挑战、提交答案和判断成功。无需挑战的学校不多一道流程。

共性基底至少覆盖：

- 图片验证码与文本答案、刷新、失效和可访问性说明；刷新请求交回脚本处理。
- 短信/邮件 OTP、TOTP、恢复码等短期输入；发送/重发由脚本调用学校协议，核心展示冷却和状态。
- MFA 方式选择、多步骤推进、外部设备批准后的等待与状态检查；脚本提供实际可用方法，核心不猜测学校默认方式。
- 滑块、交互图形、二维码或复杂厂商认证使用专用挑战页中的 WebView 区域或官方网页续接；不能将所有验证码降格成文本框。系统认证器等需平台能力的方式经独立宿主端口支持，不承诺首片全覆盖。

挑战绑定 Profile、学校、账号、批准来源、认证尝试和 challengeId，具有失效时间、取消和替换语义；迟到答案不能用于新挑战。密码输入、等待用户、网络提交分别计时，避免用户输入验证码时短请求整体超时。取消挑战能结束其所属认证流程，页面关闭后不残留读取输入的监听器。

挑战答案只用于当前流程，不进入普通缓存、日志或可持久 UI 状态；认证事务需要的临时材料由受保护会话管理。后台只能报告需要交互，不能偷偷弹输入框。核心渲染方法和状态，脚本负责学校协议与业务会话验证；只有目标服务验证成功才标为已登录。受核心托管的隧道认证可复用挑战界面，但不因此向学校脚本泄露原生隧道秘密。

## 6. 迁移、实施与验证

本决定局部替代 ADR-041 的纯原生交互定位、ADR-043/056 的有限首页能力入口、ADR-068 的无定时触发默认边界、ADR-073 的永久禁作者网页 JS 假设；这些 ADR 仍准确描述旧 SDK 的行为。ADR-046 的普通请求、无逐次额外确认和未知态保留继续成立，增加显式启用的自动化触发。ADR-072 的认证恢复继续有效，独立挑战不自动解除失败恢复门，也不重放未知业务提交。

接口落地时递增 SDK，分别定义资源包、会话、任务、挑战及卡片字段；同步 schema/类型/生成物/安装审查/消费者/迁移文档。旧 SDK 不自动获得执行网页 JS 或后台任务能力；新包不得靠新增未知字段在旧宿主执行。降级或回滚终止新会话和计划，保留可解释状态，不把新模式静默降为旧提交行为。

按以下独立切片推进，各片有单独实现状态和验证证据：通用首页入口；验证码/MFA 挑战；本地可编程网页和长期会话；远端网页增强/网络与隧道；持久任务调度。自动化任务可调用 HTTP 或网页能力，HTTP 调度不必等待全部远端 WebView 工作完成。

验证使用合成页面和账号，覆盖非白名单能力入口、展示不执行命令、多步/过期/取消挑战、长时间等待与资源回收、重复注入和导航换代、页面桥来源、全部出网通道、任务错过/重启去重/未知结果、更新与身份切换。平台后台行为、真实学校选课/认证和人工核心审阅单独验收。本文完成不代表接口、真机或学校验收完成。

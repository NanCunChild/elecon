# ADR-070 · SDK 13 包内语言资源

- 日期：2026-11-03
- 状态：Accepted（所有者要求继续实现，并明确语言资源属于脚本、作者自行选择适配语言）
- 承接：ADR-034、035、038、068。

## 声明与授权

SDK 13 新增可选 `manifest.localization`，结构为 `{ defaultLocale, messages }`；`messages` 是语言标签到纯文本字典的映射。支持语言由字典键唯一派生，作者可以只选择一种语言，也可选择核心界面尚未翻译的语言；不强制提供 zh/en/uz/ru/fa，不另维护容易漂移的 supportedLocales 数组。

语言资源直接是安装包的一部分，纳入现有 canonical JSON 的 SHA-256 digest。打包和安装校验同一格式与语义；安装无需下载外部翻译，修改任意译文需要重新批准新包。旧 SDK 带 localization 明确拒绝；不带字段的旧包保持原 digest 和运行行为。包格式仍为 elecon-script/1，SDK 与包版本独立。

标签采用 BCP 47 的明确受限配置：小写 2–3 字母语言，可选 Titlecase 四字母文字系统，可选大写二字母或三数字地区，如 `uz`、`uz-Cyrl`、`zh-Hant-TW`。本片不处理 extlang、variant、extension、private-use 或废弃别名；不能声称正则验证就是完整 IANA 注册有效性检查。官方核对入口是 IANA Language Subtag Registry，语言、文字系统与地区分别核对；具体参考与本地核对表见[脚本语言代码](../reference/script_language_codes.md)。

## 字典、回退与文本

默认语言字典是完整 key 集；其他语言允许只提供其中一部分 key，缺项逐条回退默认语言。不能添加默认语言不存在的 key。每个语言至少一条消息，最多 32 语言、每语言最多 1024 key、key 最长 128 个 ASCII 字符、单条文本最多 4096 个 Unicode code point。localization 整体 JSON UTF-8 不超过 256 KiB，仍受完整包 1 MiB 上限约束。

key 使用 `[A-Za-z][A-Za-z0-9_.-]*`。消息只支持 `{name}` 命名占位符，name 为不超过 64 字符的 ASCII 字母开头字母/数字/下划线；同一 key 的已提供译文须与默认语言拥有相同占位符集合。未匹配的花括号拒绝，因此 ICU、模板表达式和花括号转义尚不支持。文本允许正常换行/tab，拒绝 NUL 和其他 C0/C1 控制符。不执行 HTML、JS 或翻译表达式，也不自动翻译源站业务正文。

宿主在用户明确选择界面语言时使用该语言；跟随系统时保留原始系统语言，不先降级到核心已翻译语言（因此土耳其语脚本可在核心暂不支持土耳其语时匹配 `tr`）。请求标签先规范常见大小写/下划线，再按 exact → language-Script → language → defaultLocale 选择。缺省地区不随意匹配某一地区变体；例如 `zh-Hant-TW` 不匹配 `zh-Hans`。请求标签和实际选中语言分别公开为 `ctx.locale` 与 `ctx.i18n.locale`；`ctx.i18n.supportedLocales` 提供包内语言，`ctx.i18n.t(key, values?)` 提供默认回退后的文本。SDK13 未声明 localization 时只有 ctx.locale，i18n 不存在。

t 的参数必须精确提供所需占位符，且值仅 string 或有限 number；未知 key、缺失/多余参数、非法值抛固定错误，不将对象隐式序列化。参数替换是纯文本一次替换，不递归解释参数中的占位符。数字格式若有学校要求仍由脚本明确实现，语言选择不改变学期 id、时区、凭据 namespace 或业务语义。

## 缓存与迁移

语言相关调用沿现有身份、来源 digest、能力和规范参数边界，额外按请求语言隔离。语言切换取消旧代际查询，迟到结果不能覆盖新语言；不得只改文本显示而复用不匹配语言的结果缓存。旧 SDK 的参数及缓存含义不静默重解释。

首片升级 SDK/schema、Dart 解析器、工具打包器、类型和真实 QuickJS 桥，并同步模板与学校示例。后续页面元数据可引用翻译 key，但没有声明此能力的现有 manifest 名称不会被自动解释成 key；学校原文和已翻译 UI 文本继续区分。官方表是作者核对工具，不表示每个官方语言均已有翻译。

## 验证

共享合成向量验证打包器/安装器一致性、单语言与作者选语言、默认语言缺失、非法标签/未知字段/控制符/大小上限、缺项回退与占位符一致性。安装身份测试验证词典顺序无关、改变译文改变 digest、恢复保留 digest 及嵌套字典不可变。运行时与缓存测试覆盖语言协商、乌兹别克语/俄语/波斯语、参数安全、旧 SDK 表面保持与语言切换。自动测试不代替母语审校或人工核心审阅。

# ADR-081 · 脚本运行模型与文档收敛

- 日期：2026-11-04
- 状态：Accepted（所有者授权按代码审查结论进行一轮重构；实现与验证另记）
- 承接：ADR-034、041、046、065、080。本文作为本轮整体决定，不为内部拆分新增 ADR。

## 决定

作者继续编写普通 ES 模块、异步函数与异常。仅宿主调用入口进入 capabilities 注册表；辅助函数、网页事件和学校协议留在普通 JS。宿主保留身份、批准 digest、网络范围、取消、输出契约及资源管理。

本轮引入 SDK17 的统一运行环境首片：标准形状的请求/响应及取消接口按已实现子集提供，宿主专有 API 集中于 elecon 命名空间；旧 ctx 和 SDK1–16 保持原语义。未实现的标准能力明确说明，不声称完整浏览器或 Node 兼容。现有依赖优先复用，不以手写近似 URL 解析冒充 WHATWG 实现。

宿主桥以结构化成功/失败信封传递稳定错误，不解析异常的显示文本。作者继续 throw/try/catch；固定宿主分类与学校业务错误分别命名。错误分类、诊断文案和执行策略分离，错误本身不授权自动重试。只读恢复与未知提交不重放继续有效。

所有现有触发入口沿同一会话执行边界运行，调用的来源、参数、交互模式及取消语义集中管理。一次调用、长期网页会话、持久计划具有不同生命周期；本轮先整理已有调用，不虚构已实现后台调度或长期网页。ADR-080 后续功能在统一基础上实施。

文档改为现行架构、作者手册、统一实施计划与历史记录。ADR 保存原因和替代关系，不作为逐篇必读清单；旧架构流水账与验证快照归档保留，重复入口改为指向唯一维护源。归档不删除仍有调用的 V1 运行时、保护或回归；完整退役另按调用关系实施。

## 迁移与验证

SDK17 明确版本边界，旧包不自动升级；新运行接口同步类型、包校验和契约变更记录。宿主内部结构化错误改造保留旧 SDK 可见错误分类。新网页与调度接口不写入生产 manifest。

验证真实 QuickJS 桥接、成功与失败响应、取消和迟到返回、旧 SDK 兼容与非法输入，执行现有账号/浏览器/网络相关回归。文档检查相对链接、归档完整性和入口一致性。保留工作区已有变更；自动测试不替代人工核心审阅或真实学校验收。

## 本轮落地范围

SDK17 已提供模块加载前的全局 `elecon`、有界缓冲 Headers/Request/Response/fetch 与 AbortController/AbortSignal 子集，作者类型见 `contract/script-sdk/sdk17.d.ts`。未知请求选项拒绝，URL/URLSearchParams、流、Blob/FormData、浏览器 WebSocket/CORS/Cookie jar 尚未提供；不引入新依赖。局部 Abort 终止等待并忽略迟到返回，不能撤回已经发送的原生请求。

宿主桥协议与 JS 初始化从运行生命周期中拆出。业务错误由 `elecon.errors.create(localCode)` 创建，固定 code 为 `script_business_error`，独立 businessCode 为 `packageId:localCode`，仅允许有界稳定标识；宿主再次核验包前缀。旧 ctx 的请求和错误分类保留。

会话入口使用不可变调用对象，参数在首次异步等待前快照；默认来源选择固定批准 digest。文档原文及验证历史保存在 2026-11-04 快照，四份计划集中为[统一实施计划](../planning/implementation.md)。具体测试证据和未完成工作在该计划记录，长期网页、完整标准库与持久调度仍待后续实施。

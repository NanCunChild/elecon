# ADR-089 · 学校休息段与个人课表隔断

- **Decision**：Accepted（2026-11-05，所有者授权按校园体验研究落地；本决定不代表真实学校作息或人工核心审阅已完成）。
- **承接**：ADR-048 的学校时间轴、ADR-054 的整学期快照；教室可用性仍独立遵循 ADR-067。

## 决定

`schedule.week` 输出升为 **1.3**，新增可选 `breakSegments`。每项为 `label`、`timeStart`、`timeEnd`，表示脚本提供的学校休息时段；标签为当前请求语言的纯文本，时间为学校本地墙钟 `HH:mm`，使用同日半开区间 `[timeStart,timeEnd)`。最多 16 段、标签 1–40 字符；按开始时间升序、起点早于终点、段间不重叠，也不能与有效 `timeSegments` 教学段相交。没有该字段就没有具名休息提示；宿主不按时刻、间隙大小或中文名称猜测午餐/晚餐。

同版增加可选 `timeZone`（1–128 字符的 IANA 时区名称，如 `Asia/Shanghai`），明确已有学校墙钟和日历日所属时区，不改义既有时间字段。缺失、非法或平台不支持时保持未知；需要判断学校今天/下一节的系统展示必须停止推断，不能用设备时区代替。schema 仅验证有界名称语法，消费端负责验证平台支持。Android 桌面快照消费边界见 ADR-090。

休息段不禁止排课，也不声明教室可用。客户端仅在有效学校墙钟轴中画细隔断，并按每天实际已加载的课程是否相交显示休息标签；完整跨过休息段的课程仍占据该区间。提示中的无排课只描述当前加载的个人课表，不能用来补齐空教室的未知时段。跨日休息段不在本版范围。

有效 `timeSegments` 的时间轴外沿由学校分段、有效休息段与实际课程共同决定；既有 08:00–18:00/节次展示兜底只用于缺少合法学校分段的旧数据。缺失、乱序、重叠、反向、与教学段相交等不可用提示会被解码器整体忽略，保留全部有效课程；结构非法的 1.3 输出仍由版本化 schema 拒绝。课程占用统一使用半开区间相交判断，不能只检查端点落在间隙内。

本周标记沿用 `calendar.academic.currentWeek`，以常驻边框表达；查看周以背景填充表达。本周不额外占用缩略图行高，读屏与 Tooltip 保留含义。

## 版本、迁移与回滚

保留 1.0/1.1/1.2 的精确 schema 校验；输入、SDK API 与权限不变。1.3 继续沿用整学期缓存投影和原始取得时间，投影保留同快照的休息段。新学校包须声明 1.3、升包版本并重新批准 digest；旧宿主拒绝未知输出版本。旧包/缓存缺少休息段时继续原展示，不制造具名休息或学校作息。

回滚可以恢复旧客户端和声明 1.2 的学校包；包内容仍经正常安装授权，不能改 digest 绕过批准。没有新增依赖、后台请求、设备控制或公网数据路径。

## 验证边界

合成回归覆盖新旧 schema、非法墙钟与数量、提示顺序/重叠与教学段冲突、完整跨间隙课程、只有一天午间有课、无合法分段的旧回退、学校轴外沿、320px/大字号与本周/查看周区分。整学期 1.3 投影保留字段和原始时间，身份/来源隔离沿既有缓存路径。真实学校作息、设备布局及人工审阅分别记录于统一实施计划。

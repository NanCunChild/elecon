# ADR-048 周课表导航、预览与学校时间分段

- Decision: Accepted（2026-11-01，所有者要求本轮实现）。
- Landing: 原生周按钮/预览、滑动切周、覆盖冲突和学校时间分段已实施；真实学校与人工验收另行记录。

## 决策

课表采用可横向滚动的周按钮条，按钮展示该周七日课程数量预览；点击周按钮或在课表上左右滑动立即查询所选周。预览缺失表示未知，不能把未查询过的周画成无课。预览来自脚本同次取得的完整排课结果，不为绘制按钮逐周请求学校。选周仍经过当前会话、已选来源和缓存路径；来源或身份变化后清除课表及预览。

新增 `elecon.schedule.week` 1.1，保留 1.0 的精确 schema 和输出校验。原字段含义不变，新增两个可选字段：

- `timeSegments`：学校推荐的上课时间分段，每项为 `label`、`timeStart`、`timeEnd`。时间使用学校本地墙钟 `HH:mm`，同日、起点早于终点。数组按时间升序且不重叠；缺省、空数组或次序/范围不合法时客户端回退已有时间/节次轴。分段只提供时间语义，宿主决定布局。分段外课程仍保留；客户端扩展时间轴，绝不因分段遗漏课程。
- `weekPreviews`：每项含 `week` 和 `days`，每日含 `dayOfWeek` 与 `courseCount`。计数为该周该日去重后的连续排课项数，调停课后计算，单位为项；不是学分或课时数。缺失的周或日表示预览未知，零仅表示来源确认无课。数组不声明学期总周数。

SDK API 和查询参数版本不变。新学校包声明输出 1.1，旧宿主因未知输出版本拒绝安装；新宿主同时接受 1.0/1.1。已有安装包字节/digest 不改变，更新须重新授权；旧缓存继续按旧版本解码，缺少预览与分段时使用回退。

V1 工具校验只接受 registry 最新版本及显式 `previousVersions` 白名单；夹具按声明版本取得精确历史 schema，不将新 schema 套在旧输出上。未列出的版本仍拒绝，签名、official 与 Broker/Masker 门保持原边界。

七日列始终等分当前可用宽度，时间轴也占固定范围，不设撑宽手机的最小列宽。长文本在格内裁切，完整课程信息可点开查看。冲突课程占同一日列宽度并覆盖显示，显示冲突提示；点击冲突课程可列出全部相交课程再进入详情，不通过并排缩窄课程。大字号保留完整语义和详情入口。

参考 Traintime PDA 的周按钮预览、滑动切周交互。其根许可证为 MPL-2.0，周按钮文件标注 MPL-2.0 OR Apache-2.0；本轮 Flutter 组件独立编写，不复制其实现或引入依赖。现有西电 `academic.js` 的 MPL-2.0 来源与许可继续保留。

## 验证与回滚

合成数据验证：手机窄宽/大字号不横溢、点击和左右切周、第一/最后周边界、已选周缓存与错误恢复、重叠详情、未知预览、学校分段与分段外课程、旧 schema 接受、新字段非法输入拒绝。脚本测试预览随调停课变化且不增加请求；实际学校及人工审阅单独记录。回滚客户端同时回滚学校包到 1.0，按原安装授权恢复，不重解释已授权 digest。

本轮自动回归使用合成数据：Dart/TypeScript 共用版本化输出 golden；脚本验证 11 个学校节次、单双周预览、调停课计数和请求次数；Flutter 验证 320px 深浅主题/两倍字号、冲突全部课程详情、学校分段之外的课程、空周保留时间轴、周日起始校历、切周与离页后的迟到结果。原登录、缓存和解码回归继续通过。未新增依赖，未以自动测试代替真实学校验收。

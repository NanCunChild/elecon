# ADR-050：公开教师查询

- 状态：Accepted（2026-11-01 用户授权实施；代码与自动验证不代表人工安全签收）
- 范围：受信学校脚本、教师检索标准数据、原生查询页；不扩展 V1 协议算子

## 背景

教师检索具有独立的实体身份、查询和分页语义，不能将教师塞入课程目录或通知。西电教师主页官网提供无需登录的分页查询接口，字段由学校脚本归一化。

## 决策

新增 `faculty.search`，输出 `elecon.faculty.search` 1.0，参数 `elecon.params.faculty.search` 1.0。`query` 表示来源支持的姓名/关键词搜索，`researchArea` 为研究方向过滤，至少一个非空；不承诺精确姓名匹配。`page` 从 1 起，`pageSize` 为单次请求上限（1–20，默认 10）；页面仅由用户查询和翻页触发。

输出 `items`、`page`、`pageSize`、`hasMore`、`sourceSystem`、`sourceUrl` 必填，`total` 可选且缺失表示来源未提供总数。实体 `id` 在学校和来源系统内稳定，不按姓名合并同名教师。姓名必填；学院、职称、学科、研究方向、简介摘录和公开主页可缺失，不用空字符串或 null 假造已知数据。所有正文为纯文本；主页仅作来源链接，禁止下发可执行 UI。

查询由已授权学校包执行，仍受 digest、网络范围、取消与资源预算约束。西电实现只直接读取公开官网，不读取或转发凭据、不走公共中继、不收集手机号等额外信息。每次查询一页，不自动拉全量，不预加载首页、不持久缓存检索结果。

客户端在支持该能力的学校展示“教师查询”，原生搜索与分页控件复用该查询的数据。列表展开显示同一结果的简介与主页，不重新选择提供者；整个页面绑定打开时的学校、会话和安装/来源代际，失效后清空结果并拒绝晚到响应。

## 兼容与迁移

这是新增能力与 schema，不改变任何已有字段含义。旧学校包没有该能力时不展示入口。新增声明随包版本更新（西电 0.17.0），增加 `https://faculty.xidian.edu.cn` 网络范围，安装更新照常重新确认。未支持新 schema 的旧宿主按现有规则拒绝安装/执行，不降低校验。SDK 不新增原生 API，也不新增任意页面注册机制或 manifest 卡片类型。

## 验证与回滚

使用合成教师响应验证查询编码、分页、同名实体、空结果、损坏数据、纯文本归一和不读取凭据；通过真实 QuickJS 包执行验证宿主桥接。Widget 回归验证手动查询、分页重置、失败/空态、详情和会话/安装代际失效。官网研究仅为低频公开请求的观察，不能代替持续可用性或人工验收。

回滚可移除学校包的能力声明与首页入口；旧 schema/能力不受影响。核心输出注册和网络边界实现仍须人工实质审阅后合并。

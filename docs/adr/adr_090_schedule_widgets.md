# ADR-090 · 前台缓存驱动的 Android 课表小部件

- 日期：2026-11-05
- 状态：Accepted（所有者授权按校园体验研究落地；实现和平台验收分别记录）
- 承接：ADR-038、044、054、066、085。

## 决定

Android 使用 `AppWidgetProvider + RemoteViews` 展示今日课程及下一节课，只消费前台已经验证的课表缓存。小部件不执行学校脚本、不请求网络、不解锁凭据、不持有完整业务缓存或主密钥，不新增依赖、精确闹钟、后台服务或宿主 SDK 权限。

每个实例经原生配置页明确同意显示课程名称、时间和地点，绑定当前 Profile、学校、批准来源包/digest。配置页说明 Launcher 已收到的内容可能被其缓存或截图，后续遮蔽不承诺收回。点击仅传实例 ID，应用恢复后重新核验当前身份和批准来源，再进入固定来源的课表页；不能悄悄切身份或改用另一个提供者。

H/S 档使用 AndroidKeyStore 独立 AES-GCM 密钥加密最小快照和实例授权，存于应用 noBackupFilesDir；M 档只在内存。原生进程重建后默认遮蔽，直到主应用完成正常身份/批准来源核验并重新授予同作用域快照，不能仅凭进程内 generation 恢复。未解锁或没有有效快照时显示“打开 elecon 更新”，不能画成今日无课。首次从 Launcher 配置时，若应用尚未恢复 Profile/学校，先打开应用完成正常恢复，再返回配置页授权。多个实例分别绑定作用域；切身份/学校、登录使业务数据代际变化、来源禁用/更新/移除均清除旧授权和快照，重新显示需要用户再配置。受保护 CredentialStore 内的随机账号代际 token 随显式登录的缓存清除一起持久删除；登出/重置同样删除。该 token 使用保留地址，不是学校凭据，不对脚本开放，也不计入已登录判断。语言变化刷新展示，不变更数据原始时效。

宿主桥只传版本 1 的有界展示投影：作用域不可逆 token、日期、明确学校时区、原始取得/过期时间、按日期分组的已知课程；每份最多 7 日、每日最多 32 项、每字段限长。日期与时间依据脚本的明确日历及课程字段，不从设备时区猜学校时区。没有时区证据的旧课表显示不可用；缺日数据为未知，只有明确空的日条目才表示无课。未给出真实墙钟时间的课程可列出学校节次，但不能推断为下一节课。

原生桥在主线程串行处理作用域撤销和快照写入，写入必须匹配最新 token；Dart 每次异步读取后再次检查 Profile、学校、身份、业务数据代际、批准 digest。原生恢复的磁盘记录仅在主应用重新核验相同 Profile/学校/账号 token/批准 digest 后可展示；加密/解密失败不回退为明文。系统锁定时重绘只显示遮蔽提示；进程在运行时监听锁屏/解锁事件，进程不在时等下次系统更新重绘，因此同样不能保证立即收回 Launcher 的旧画面。

系统周期更新为 30 分钟，并在前台缓存更新、大小/日期/时区改变时重绘已有快照。重绘不修改 fetchedAt，不等于重新查询成功；过期显示缓存标记。下一节课只是本次重绘时的计算，不承诺整点或每分钟刷新。官方依据：[配置页](https://developer.android.com/develop/ui/views/appwidgets/configuration)、[更新限制](https://developer.android.com/develop/ui/views/appwidgets/advanced)。

## 兼容、验证与回滚

这是 Android 展示桥版本，不增加脚本 manifest 字段。旧包在缺少必要时间证据时保持不可用；课表时间字段的版本由领域契约独立管理。进程重建后需要打开应用核验的限制明确显示给用户；不在后台恢复完整凭据或执行学校协议。

验证原始时效、已知无课/未知、无墙钟时间、旧时区缺失、跨日/跨周、过期、身份/来源撤销、迟到读写、M 档无落盘、点击固定来源与不同实例。真实 Launcher 配置/缩放/进程重启属于平台验收；自动测试和构建不替代。回滚删除 provider/configuration/bridge 和 Flutter 监听，不改变任何学校凭据、SDK 或业务数据。

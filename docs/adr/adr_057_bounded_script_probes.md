# ADR-057 有界脚本阶段探针

- **Decision**：Accepted（2026-11-02，所有者要求为失败签到增加可提取日志的探针）。
- **Landing**：已实现通用校验、正式版筛选/复制及学习通 0.2.1 阶段探针；自动回归、真实活动验收与人工网络/日志审阅分别记录。

## 决策与边界

沿用 SDK `ctx.log`，增加宿主理解的通用阶段记录格式，不新增权限或 SDK API，不将学习通协议放入核心。受信脚本可以发送 `probe/1 stage=N event=E http=H ms=T flags=F`：阶段 N 为 1–32，事件 E 为 begin/ok/failed/unknown/skipped，HTTP H 为 0（无响应）或 100–599，耗时 T 为 0–120000 整数毫秒，F 为恰好八位 0/1/?（未知）。阶段与条件位的业务含义由脚本文档说明；宿主只理解格式。

宿主严格匹配整行、校验范围并重建文本，不接收额外字段、URL、响应正文、错误原文、活动/账号标识、二维码或位置。日志仅进入本机既有 500 条环缓冲；不持久化、不发送外网。正式版设置日志页可查看与主动复制 network/probe，DevLog 的其他脚本自由文本仍只在 debug 可见；脚本工作台主动运行的既有日志面板不在此策略变更范围。Script SDK 的既有每次调用 100 条/64 KiB 限制继续适用。此约束减少意外泄露，不声称可以阻止受信脚本通过数值编码任意秘密。

学习通脚本标记认证、扫码、要求检查、analysis、preSign、单次提交及独立核验阶段。只记录状态、耗时、固定条件位，记录失败不改变控制流程、不增加请求、不自动重试。提交后不确定性保持 unknown，探针不是成功证据。旧客户端忽略新格式的正式版记录；旧脚本不受影响。更新脚本仍需授权新 digest。

## 验证与回滚

验证完整匹配、越界/尾随原文/秘密字段拒绝、日志与剪贴板只接收规范化记录、现有 debug/release 策略保持，以及脚本合成失败覆盖和真实 QuickJS。实际学校活动仍需用户现场复现并提供探针；自动测试不能证明线上签到修复。回滚移除 probe 桥接或恢复旧包，不影响身份、网络范围与执行授权。

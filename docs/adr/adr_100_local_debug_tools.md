# ADR-100 · 本地调试文件入口与日志

- 状态：Accepted（用户于2026-11-10要求实现；人工安全审阅另计）
- 范围：客户端本地开发；不新增 SDK 或包 manifest 字段。

调试时需要通过 ADB 或私有文件快速添加、替换、删除学校脚本，并读取超出 UI 环缓冲的日志。

Debug 构建（`kDebugMode`）默认轮询 application support 下 `debug-tools/inbox`，不另设变量开关。开发者写入命令即授权该次本地安装：命令固定 Profile，包含完整源码包及原文件 SHA-256；宿主正常解析、校验并保存其规范 digest。此入口替代调试设备上的逐次安装页审查，不能用于生产授权。允许同版本换源码，仍拒绝降版和换学校，保留来源选择，沿用 Session 安装/删除失效、缓存及身份边界。不执行包能力、不自动登录、不发送命令；V1 不经过此入口。Profile/Release 构建不提供此入口。不能从共享外部存储或导出广播取得命令。

2026-11-10 审查修正：按所有者要求取消最初的 `ELECON_DEBUG_TOOLS` 编译开关，开发调试只由 Flutter 构建模式决定。V1 的 `ELECON_TRUST_PROFILE` 仍仅用于兼容路径，不控制新源码导入或本地调试工具。

轮询只在前台、Profile 已恢复且未切换时处理，命令目标必须匹配当前 Profile；身份不匹配返回固定错误。异步文件读取和注册表排队后、开始安装/删除提交前重新核验生命周期；期间切后台或关闭入口使该命令失效，回到前台不恢复这次授权。已经开始的持久化提交仍按实际结果记录，不能宣称取消能回滚落盘。临时文件 rename 成就绪 JSON 后消费，执行前移出 inbox；进程中断留下 processing 文件，结果视为未知，不自动重放。结果保存在按请求 ID 寻址的 JSON，开发工具读取后删除。包大小、队列批次与结果保留均有界。无任意文件路径或能力调用入口。

Debug 构建将 DevLog 已净化条目异步写入私有 JSONL（4份，每份4MiB目标上限；单条不截断，超限条目独立占一份），保留时间、类别、状态；新增脚本调用标识/耗时与 HTTP 状态/耗时。磁盘与排队失败不改变业务结果，丢弃计数明确记录。ADB `run-as` 读取保留范围的完整条目；轮转过期、崩溃前未刷入和排队溢出不能承诺保留。凭据脱敏不可关闭，不记录请求/响应正文或完整凭据；不上传。日志清理与 UI 清空分别操作。

应用标识改为 `com.ncclab.elecon`，包括 Android namespace/组件、Apple bundle ID 和 Linux application ID。旧包与新包为不同安装身份，不能覆盖或自动继承原私有数据/Keystore；旧安装保留，开发者在新包重新安装脚本并登录。DEV-SIDELOAD 仍使用独立后缀。

验证包括同版本替换与错误摘要拒绝、Profile/发布门、异步读取及提交排队期间失去前台、关闭入口、原子消费及不重放、来源失效、日志轮转/长消息/脱敏/失败，以及 Android 构建与组件引用。合成测试和构建不是学校验收或人工签收。回滚可还原本地调试入口实现、恢复应用标识；不迁移旧身份密钥。

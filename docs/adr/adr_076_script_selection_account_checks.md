# ADR-076 · 脚本切换反馈与账号检查

- 日期：2026-11-03
- 状态：Accepted（所有者要求切换脚本后明确提示并检查账号有效性）
- 承接：ADR-043、066、072；凭据复用另见 ADR-077。

用户选择学校脚本、切换能力来源或恢复默认来源后，客户端立即说明实际选中的来源，并调用该批准包声明的账号 status 入口。按当前 Profile、学校、包 digest 和执行代际固定检查；后续切换、撤销或退出丢弃迟到结果。只检查当前学校的来源，不为另一学校调用凭据。

检查只使用 `account.session` 的 status 声明，禁浏览器、表单、密码登录和其它交互。不触发 login、命令或密码重试。无账号声明或缺失 status 的旧包显示“未提供检查”，不能将保存凭据、空结果、网络失败视为登录有效。返回 authenticated / signedOut / expired / unknown；页面保留账号名称和各自状态，并给出账号设置入口。

宿主调度检查、取消和提示；脚本负责源站成功判定以及只读母票据换签、子服务验证。子服务 401 不证明主账号过期，网络失败保留 unknown。来源选择不删除同校凭据，也不把旧来源状态移植到新来源。

此切片复用 SDK12 的 status 声明，不改变旧包含义。验证包含实际脚本状态返回、无声明、失败、禁止交互及切换后迟到结果；真实学校与人工凭据审阅分别验收。

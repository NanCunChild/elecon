# 2026-11-03 功能补充实施切片

依据 [ADR-067](../../../../adr/adr_067_classroom_availability_intervals.md)、[ADR-068](../../../../adr/adr_068_script_interaction_and_recovery.md)；本表区分设计与实际代码，不将未实现声明加入学校包。

| 需求 | 本轮落点 | 尚需完成 |
|---|---|---|
| 空教室时段、原因、当前线与指定时间 | ADR-067 版本化区间；ADR-071 同来源脚本日期/房间/时间范围控件 | 真实学校时间表/占用原因验收、更多标准领域条件 |
| 成绩无效与筛选 | 对照现有 PDA 请求参数；ADR-071 脚本学期选项、提交、GPA 与缓存联动 | 真实账号查询、多种学校条件、跨学期新契约 |
| APPTunnel / Hermes | 协议研究、已有传输回归、失效码及状态检查 SID 持久化修复 | 见 [Hermes 对齐研究](../../../../research/hermes_zju_connect_alignment.md)；真实网关/目标连接及 WebView 隧道 |
| 凭据优先、隐形换签、账号事件 | ADR-072 SDK14 声明/账号事件、验证后保存/更新/删除密码、持久一次额度；IDS 换子票据继续保留 | 隐藏 presenter 的完整网络边界与实际自动恢复、真实学校验收 |
| 内嵌网页和构建 DOM | ADR-073 包 HTML 授权、Android 网页入口/嵌入区域、固定 DOM 与真实用户事件；文档脚本/直接网络关闭 | 任意远端表单、WebView APPTunnel 与完整远端网络覆盖 |
| 乌兹别克语、俄语、波斯语 | 核心 uz/ru/fa ARB 与 RTL；ADR-070 的 SDK13 作者自选包语言、安装审查、locale/i18n、语言缓存与[官方代码参考](../../../../reference/script_language_codes.md) | 历史硬编码文案迁移、学校全部 UI 文案迁移、母语审校 |
| Android 17 系统 AI | ADR-074 固定四个 AppFunctions、临时用户授权、当前身份/取消/输出投影及 KSP 注册 | 真实学校 AI 查询与平台助手开放验收；不由系统登记推导 Gemini 可调用 |

优先顺序：修复已有查询和可验证页面 → 统一条件/账号声明 → 认证恢复和共享浏览器 presenter → 包资源/国际化与网页模板 → 系统 AI 只读能力。恢复协议是隐藏 WebView 的前置；浏览器传输覆盖是隧道模式使用网页登录/填表的前置。平台 AI 只复用已经具备完整契约的查询，不先暴露通用脚本执行口。

当前 ADB 授权设备经只读检查为 API 35；连通和 root 授权不代表学校密码、网关凭据或 Android 17 已验收。工作中不得把真实凭据、页面正文、设备标识写入夹具或提交。

网页验证补充：最终 **42 项**浏览器、固定 DOM、安装审查与网页入口回归通过，定向静态分析无问题。在 **API37 Android 模拟器**运行纯合成网页：实际触摸网页提交按钮得到 `WEB_CONTENT_SMOKE_PASS`，重启后点击原生取消按钮得到 `WEB_CONTENT_SMOKE_CANCEL_PASS`；两者均在原生清理并释放独占租约后才报告通过。验证包含文档脚本/onerror 不执行、固定 DOM 读写、任意 evaluate 拒绝，以及合成 HTTPS 主文档只由授权 HTML 内存响应提供、无网络回退。此前 loadData 主请求被拦截及状态行变化重建原生区域的问题已修复并补回归。详见[浏览器参考](../../../../reference/script_browser_surfaces.md)。这些结果不包含真实学校提交；任意远端学校网页、隐藏远端 WebView 和 WebView APPTunnel 仍未开放。


## 受信脚本扩展（ADR-080）

2026-11-04 所有者要求以跨学校共性基底支持更灵活的受信扩展，方向见 [ADR-080](../../../../adr/adr_080_trusted_script_extensibility.md)。下列切片均为**已接受方向、接口与代码待实施**；上文 ADR-073 的禁作者 JS 回归只证明旧模式行为，不是新模式验收。

| 切片 | 核心交付与脚本职责 | 关键验证 / 兼容 |
|---|---|---|
| E1 通用首页入口 | 拆开卡片类型与能力白名单；绑定来源/参数/输入/展示/触发；脚本提供声明，共性结果复用原生组件，无专用组件时有通用入口或网页 | 所有已声明可执行能力可绑定；展示不发送命令；多实例固定来源；旧卡片布局与缓存保留 |
| E2 验证码与 MFA | 独立挑战页、认证尝试会话、图片/OTP/方式选择/等待批准/网页挑战；脚本获取、刷新、提交和验证 | 多步骤、失效替换、取消、迟到答案、后台等待、秘密不进日志；保留官方网页路径 |
| E3 可编程网页与长期会话 | 包资源纳入 digest，支持作者 JS/DOM/SVG/Canvas，分离会话存活与执行预算，提供事件桥和停止入口 | 本地绘图/按钮、多模块、长期等待、资源回收、更新/退出撤销；先支持本地网页，旧离线模式不变 |
| E4 远端网页增强 | 导航/框架注入和清理、特权上下文隔离、完整网络边界与 APPTunnel；脚本编排页面行为 | 页面不能冒用桥、跨导航不重复挂接、出网覆盖与无直连回退；逐平台记录能力 |
| E5 自动化调度 | 用户启用计划、时间/时区/错过策略、持久运行标识、任务状态和取消；脚本选择业务条件、HTTP 或网页执行路径 | 前后台与进程退出分别验收；重启不重复提交、未知不重发、认证等待、来源更新与身份撤销 |

E1、E2 可独立推进；E3 先完成本地 JS，再推进 E4。E5 的 HTTP 执行无需等待 E4，网页自动化依赖相应会话和传输能力。各片落地时冻结 SDK/schema、补类型与消费者、记录回滚方式；没有接口前不修改生产学校包来声明这些能力。

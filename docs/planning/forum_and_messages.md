# 论坛与消息系统实施计划

> 更新：2026-11-02。依据 [ADR-051](../adr/adr_051_forum_and_messages_reservation.md) 及 [ADR-052](../adr/adr_052_community_accounts_and_chaoxing.md)；已实现睿思账号连接、学习通前台群消息窗口与受限扫码签到，导航按可执行能力显示。ADR-061 已补齐群/私聊历史、文本发送及核心 SQLite；帖子、未读与推送仍待实施。相关通用来源/分页方向见 [platform_evolution](platform_evolution.md)，当前账号边界见 [ADR-044](../adr/adr_044_local_profiles.md)。

## 产品范围与待定事项

论坛提供板块、主题、正文与回复；首个数据切片只读。消息面向回复、提及、站内信等属于明确服务账号的收件内容，与首页学校公告分别呈现。能匿名浏览论坛的服务不强制登录；需登录才可读的服务展示其明确登录要求。未登录、未加载、读取失败与已加载空列表分别表示，未取得未读计数时不画“0”。

首个来源已按所有者指定：基本包接入睿思账号，独立学习通增强包接入群消息与扫码签到。自建 elecon 社区尚无决策。后续接入更多来源时，先确认接口/使用授权、是否允许匿名浏览、登录方式、稳定用户 ID、学校归属、分页、消息/未读能力和会话撤销。自有服务还需独立决定注册/找回/注销、内容审核与举报、反滥用、数据保留和私密消息的访问授权，不复用静态脚本分发后端。

睿思账号独立于学校账号；当前提供明确的睿思登录与本地退出，先退出再换号。按 ADR-053，服务失败/取消不改变学校会话和课表，离页只取消本页调用。学习通作为第三方社区包自行导入，客户端无内置产物或推荐提示；采用原站可见登录，与教务和睿思会话分别保存。关联学校身份必须显式授权，不能自动发送学号、学校 cookie 或学校登录凭据。

## 身份、缓存与取消设计（长期方向；首片边界见 ADR-052）

| 对象 | 拟定语义与边界 |
|---|---|
| Profile | 沿用本地独立会话边界，不是远端注册账号；切换时销毁旧导航、草稿视图、请求与临时正文 |
| Service | 稳定服务 ID、受审核源与认证方式；展示名/域名变更不自动改变主体；切校后的可用范围由服务声明与授权确定 |
| Account | 服务给出的稳定 ID；显示名仅作展示，学校用户与论坛用户不靠相同文本合并 |
| Session | 每个 Profile/service/account 独立凭据与执行代际；退出服务取消在途请求、清除该账号敏感缓存及未读状态，不退出学校 |
| Entity | 主题、回复、会话、消息以来源和远端 ID 组合寻址；列表、详情、分页、未读更新绑定同一账号和提供者 |
| Cache | 至少按 Profile、service、account（匿名有独立范围）、学校授权范围及提供者批准 digest 隔离；保留取得时间、原始时间、分页与 stale/partial |

切校不自动把新学校凭据授予论坛。学校绑定服务先停止旧范围请求，重新验证可用性；跨校独立服务也要保留明确服务账号身份。退出一个学校会话与退出独立服务不是同一操作；按服务实际撤销机制处理，不承诺未实现的远端注销。禁用/更新脚本使旧批准 digest 的结果不可读，晚到结果不可进入新账号/来源；当前 SDK namespace 不提供跨脚本凭据隔离。

私信正文、附件、草稿不进入公共缓存、诊断日志或共享首页偏好。持久化是否开启、TTL、附件访问和退出清除策略在账号 ADR 中决定；旧 messages.list 窗口仅驻留当前可见页面，不持久化；新增会话/历史/文本发送按 ADR-061 由核心以 H/S/M 保护 SQLite 快照，离页清除视图/草稿，退出账号或撤销来源清除库。消息未读状态的本地值不能代替服务确认，显示正文也不应隐式触发标记已读。

## 领域契约与后续准备

ADR-052 已注册 `forum.session`、`messages.session`、`messages.list`、`attendance.checkin` 1.0；不复用 notice/attendance.summary。消息仅表示当前前台窗口，不保证历史完整性。ADR-061 新增 messages.conversations/history/send 1.0；下表是更完整的帖子/收件箱设计清单，不代表这些全部已经实现。

| 领域 | 契约需要明确的内容 |
|---|---|
| 板块与主题列表 | 板块/主题稳定 ID、账号可读范围、标题、作者显示身份、置顶/锁定/删除/审核状态、排序、过滤和游标分页 |
| 主题与回复 | 同源主题/回复 ID、作者、楼层或位置（不猜补缺号）、引用/编辑/删除状态、创建/更新时间、富正文和附件 |
| 收件列表与详情 | 来源、账号、消息稳定 ID、类别、发送方、会话/主题引用、收到时间、可选阅读时间及分页；缺失阅读状态表示未知 |
| 未读与同步 | 服务确认的计数与统计范围、同步游标、去重、已删除/撤回、断线补拉、过期游标和局部失败；不由当前页条数猜总数 |
| 错误与权限 | 登录过期、缺权限、不存在/已删除、限流、离线和服务不支持分别表达；不可读正文不得被旧账号缓存补回 |

时间区分 RFC3339 时刻与日历日，缺失值不伪造零/false，分页保存 next cursor 与完整性。正文由宿主有界渲染，链接/附件保留来源并受实际账号和网络授权约束，不执行文章脚本，不把鉴权 URL 交给通用 UI 任意请求。来源变更后不能拿旧 ID 向新提供者查详情。

纯文本发送按 ADR-061 已实现一次发送与匹配确认；发帖/回复、标记已读、删除等仍安排在后续独立切片。需明确每个操作的输入、幂等支持、取消、发送中、已确认、结果未知与对账方式；禁自动重发或切源重试。受信脚本传输沿 ADR-046 的通用请求，不重新引入已废除的 action 字段；不在本轮先实现通用写操作框架。

## 按依赖实施

| 切片 | 内容与位置 | 验收与回滚 |
|---|---|---|
| F0 入口已实现 | 首页/设置固定；论坛/消息按当前学校可执行 provider 出现，统一两种底栏 | 安装/禁用/切校/来源撤销回归，稳定选中页；无需写数据迁移 |
| F1 首片已实现 | 睿思独立账号、学习通原站登录；按 Profile/学校/服务分别保存 Cookie，一个平台一个会话 | 合成与 QuickJS 回归；持久消息由 ADR-061 实现，多账号槽位未实现，仍待真实账号与人工审阅 |
| F2 论坛只读 | 领域 schema/registry/生成物/decoder、板块/主题/回复、同源详情、固定原生分页与正文 | 合成 fixture → 实际接入代码 → 标准输出 → 页面；loading/error/empty/stale/partial、撤回、权限与分页；保留入口可单独停用提供者 |
| F3 历史已实现 | ADR-061 会话、群聊/私聊历史分页、核心 SQLite、去重/撤回与离线已加载记录；旧窗口兼容 | 自动模块/QuickJS/存储/页面回归；未读尚未实现，真实账号/真机与人工审阅待验收 |
| F4 文本发送已实现 | ADR-061 单次纯文本发送、确认/拒绝/未知；发帖/回复与阅读状态仍待设计 | 用户触发、服务幂等键（若支持）、网络失败未知态、取消与对账、禁止自动重试；实际账号验收单独授权 |
| F5 后台与推送 | 服务确有支持且用户授权后再设计通知权限、设备 token、预算、断线/前后台去重与撤销 | 推送正文暴露策略、退出解绑、Profile 切换、离线补拉与平台真机；不把后台能力写进当前 manifest |

F1 在 F2/F3 之前；F2 与 F3 可按目标服务分步交付。消息无需等待完整通用增强平台，但必须具备自己的账号与同源实体边界。匿名论坛不能被描述成现有的低权限脚本沙箱；涉及宿主新权限的设计先另立 ADR。

## 本轮交付与剩余验收

本轮交付见 ADR-052/053/055：基本包 0.19.0 睿思账号、SDK 9 第三方学习通社区包 0.2.0、群消息窗口、受限扫码签到与按能力显示的导航。签到 1.1 增加原生可编辑地点矩阵及固定失败原因；地点需用户主动选择，坐标不推断，提交不自动重试。当前论坛页仅连接账号。ADR-061 的社区包 0.3.0 新增会话、群/私聊历史、文本发送和核心受保护 SQLite；作业、课程、任务只显示摘要。没有帖子、未读数、发帖、附件操作、自动轮询、推送或后端部署。

验证覆盖合成协议、实际编译包 QuickJS、TLS 与连接预算、动态导航和旧脚本兼容。真实学校/服务账号、原生扫码/WebView 真机及安全人工审阅仍待验收；自动测试不代替这些证据。

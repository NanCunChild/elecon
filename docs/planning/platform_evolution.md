# 页面、增强包与中继实施计划

> 更新：2026-10-31。文档重整依据 [ADR-041](../adr/adr_041_current_architecture.md)已执行；[ADR-042](../adr/adr_042_providers_pages_enhancements.md)是 Proposed。本轮已实施的独立客户端切片见下方 ADR-043 进度；表中完整平台阶段仍按各自验收，不批量标记完成。现行脚本验收仍看 [trusted_scripts](trusted_scripts.md)。

## 目标与顺序

先让数据来源和参数可确定，再把课表移出首页，最后以公开通知验证增强包和中继的完整使用链路。图书、论坛复用这条链路；私密中继等待实际授权和身份设计，避免先搭一个什么都代理的服务。

```mermaid
flowchart LR
  D[文档与基线 已完成] --> C[参数和 decoder]
  C --> P[独立课表与查询状态]
  C --> B[显式 provider 绑定]
  B --> A[匿名增强权限]
  A --> N[公开通知中继试点]
  P --> L[图书检索与论坛只读页]
  N --> R[有授权的空教室试点]
```

## 可独立评审的切片

| 阶段 | 工作与涉及位置 | 完成证据 | 回滚/兼容 |
|---|---|---|---|
| D0 文档治理 | 新 AGENTS/架构/规则；旧文档 archived 与跳转；提案、研究和计划 | 本地链接、档案清单、diff、分步 unsigned commit | 仅文档，无运行时变化 |
| C1 契约输入与解码 | `contract/capability`、参数 schema、codegen、`runtime.dart`、`ui/home/schema_decode.dart`；先补 notice.detail 和分页元信息 | 非法输入执行前拒绝；旧版本fixture不漂移；分页完整往返 | 新版本/兼容 facade，不收紧旧版而不通知 |
| P1 页面状态提取 | 从 `capability_sections.dart` 提取 query repository/controller，固定页面注册；课表成为独立路由 | 首页与独立课表同查询结果；离开/切校/刷新负例；无学校协议进入UI | 保留首页摘要，逐页面迁移 |
| B1 提供者绑定 | registry、session、详情实体引用、预加载与缓存；明确主包/增强绑定 | 安装更新不抢占；详情/分页不换源；禁用恢复主包；未选包不预加载 | 逐能力保留现有来源；异源列表/详情待明确选择；坏绑定不可用 |
| A1 匿名增强 profile | 新 SDK/profile、宿主能力裁剪、安装说明、模板及负例 | 无凭据API、无浏览器/学校会话/私密参数；所有出网限审计过的公开端点/方法；旧SDK保留 | 旧宿主拒绝新SDK；不得降级到高信任模板 |
| N1 公开通知服务 | 独立采集部署、匿名公开源、共享纯解析、快照、条件请求、限流熔断 | 合成故障/负载测试、有限真实源核验、数据公开许可确认、实测指标 | 用户一键禁用增强恢复原通知；不删除直连 |
| N2 客户端通知增强 | 安装 → 检查 → 绑定 list/detail → 显示来源时间 → 离线/失效 → 禁用 | 同源实体、原始采集时间、撤回、硬过期、只读回退演示 | 主包独立可用；无需更换学校身份 |
| L1 领域增量 | 图书 search/detail/holdings 与论坛 board/thread/reply 各有 schema ADR；只读页 | ID语义、分页、过滤、富正文、错误和权限独立验证 | 不改变 library.loans / notice 含义 |
| R1 条件性私密/校内服务 | 空教室共享授权、账户模型；水电本地缓存先行 | 学校授权证据、身份隔离、预算、实际可用性与撤销 | 缺授权则保持直连；不提供全校水电缓存 |
| W1 后续写操作 | 论坛发帖/回复、图书续借/预约等独立 command 设计 | 确认、幂等/未知态、取消、不跨源重试、人工审阅 | 不混入 query 或复用 climate 特定 payload |

C1/B1/A1 及领域变更在 ADR-042 或对应细分 ADR 接受后实施。D0 不代表这些阶段已接受。每片单一目的提交、独立回滚；不得用文档进度代替运行时证据。

B1 首版按单校单活动账户工作，预留独立 IdentityId；切换账户使旧绑定上下文和缓存失效。多账户完整迁移是私密增强的前置，不能因账户模型排在 R1 就在 B1 用 schoolId 宣称账户隔离。

## 模板交付要求

现有 `adapters/_template/trusted/http` 是高信任学校会话示例。后续分别提供：学校直连包模板、无凭据公开增强模板、纯解析/fixture模板、客户端 feature/page模板。模板的 README 必须说明适用SDK、能力/参数/结果版本、权限、缓存/分页、错误、实体来源及验证命令。

匿名模板在 A1 实现前只留设计，不发布可导入的伪低权限包。主包与增强包之间采用宿主标准能力组合，不让作者复制主包认证代码、硬编码对方存储键或通过 monkey patch 修改主包对象。

## 试点怎样实际使用

N1/N2 完成后，用户先安装并验证主学校包，再独立安装通知增强包，检查零凭据权限和公开源域名；选择“通知”数据来源时同时绑定列表与详情。页面标注来源与采集时间，网络失败可显示允许时限内的旧数据；退出增强后恢复主包。此流程目前是验收脚本，不是现有 App 操作教程。

空教室另走 R1：授权、校区楼栋/日期/时间段、缓存窗口与最大查询预算先确定。水电只能针对用户获授权的电表或水表，不枚举全校，不用宿舍号当公共授权。详细参数与演练见[中继研究](../research/relay_enhancement_feasibility.md)。

## 验收与决策记录

| 事项 | 当前状态 | 如何关闭 |
|---|---|---|
| 旧文档退出默认主线 | 已整理 | 文档检查与提交记录 |
| provider 与页面抽象 | 提案 | ADR接受及C1/P1/B1实现证据 |
| 匿名增强权限 | 未实现 | A1负例与人工核心审阅 |
| 通知解析夹具 | 现有合成测试可运行 | 研究记录仅证明解析，不代表N1/N2完成 |
| 中继加速幅度 | 未测量 | 记录命中率、请求数、p50/p95、错误/过期率和源站压力 |
| 通知公开采集/再发布 | 待实际源核验 | 无登录可读、缓存头/使用条款、学校许可或可发布依据 |
| 空教室共享查询 | 待授权 | 服务身份、发布范围、预算与撤销 |
| 同校多账户 / 身份增强 | 待专项设计 | 存储/缓存/凭据/授权的账户隔离方案 |
| “课标”业务含义 | 未确认 | 课表与课程标准暂分开；不重解释 schedule.week |

技术目标值是拟验收门槛，不是实测成绩。上线需实际部署、监控、回滚、授权与必要人工审阅；本轮没有部署服务或对学校发起压测。

## ADR-043 首个客户端切片

已实现：SDK 6 可选 cards 建议、四类三档原生卡片、首页长按编辑/拖动排序/角落调整尺寸、学校级布局持久化、工作台同名能力来源覆盖、稳定默认来源及取消边界。具体使用见[说明](../reference/card_layout_and_overrides.md)。

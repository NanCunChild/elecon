## 受信扩展

以下方向已由 [ADR-080](../adr/adr_080_trusted_script_extensibility.md) 接受，接口与代码仍待实施，不得先加入生产包声明。

| 切片 | 交付 | 验证与依赖 |
|---|---|---|
| E1 全部能力首页入口 | 分离卡片类型、来源、参数、展示及触发；无专用组件时有通用入口或网页 | 所有已声明可执行能力可绑定，显示不执行命令，多实例与用户布局保留 |
| E2 验证码 / MFA | 独立挑战页和认证尝试会话；图片、OTP、方法选择、批准等待及复杂网页挑战；脚本获取/刷新/提交/验证 | 过期、替换、取消、迟到答案、后台等待及秘密处理；保留官方网页路径 |
| E3 本地 JS 与长期网页 | 包资源纳入 digest；DOM/SVG/Canvas 与事件桥；会话存活和 CPU/内存预算分别管理 | 多模块、长时间等待、停止、回收、更新和身份撤销；旧离线模式保留 |
| E4 远端网页增强 | 注入/重挂/清理、特权上下文隔离、完整网络范围和 WebView APPTunnel | 桥来源、导航换代、全部出网路径、无直连回退；逐平台验证 |
| E5 持久调度 | 用户启用计划、时间/时区/错过策略、持久运行标识与状态；脚本提供业务条件 | 前后台与进程退出分开验收；重启去重、未知不重放、认证等待、更新与身份撤销 |

E1/E2 可独立推进；E3 本地模式先于 E4。E5 的 HTTP 路径无需等待全部 E4，网页自动化依赖相应会话与传输。每片冻结版本化契约、同步类型/消费者并记录回滚；不用单纯删除 CSP 或扩大超时替代完整实现。

## ADR-082 · 脚本查询表单与空教室首片

所有者已接受“有限控件类型、脚本创建业务字段”方案并授权实施。核心支持 text/number/boolean/select/multiSelect/date/timeRange，每表单最多 32 项；字段 id、标签、约束、选项与依赖由脚本决定。新 `filters` 容器与宿主参数分离，元数据和草稿有大小限制，来源/身份/语言变化使草稿失效；依赖刷新失败可重试，取消保留原查询，显式提交后才查询。

| 切片 | 当前交付 | 剩余范围 |
|---|---|---|
| 契约及兼容 | query.controls/params.query.controls 2.0；grades 输入 1.1、classroom 输入 1.2；classroom 输出 1.3。保留精确旧版快照和原生旧表单；同步包准入、生成器、SDK 类型与示例 | 输入支持由同来源 query.controls 2.0 协商；无需新 SDK 权限；旧宿主按未知版本拒绝 |

| App 0.8.0+11 | 默认及 Apple 版本同步，内置两个学校包更新，时间轴和旧布局保留属性，AppFunctions 接受新输出版本 | 未发布、打 tag 或安装到设备；AI 缺楼栋提示仍是上表独立待办 |

## 维护方式

## 2026-11-10 · 并行审查修正与学习通成员研究

客户端默认/Apple及版本展示升 **0.10.1+18**，学习通两角色增强包升 **0.7.5 / SDK20**；基础包仍为0.33.0。沿用 ADR-038/057/098/099；依据ADR-098的302修正，仅新增固定头像CDN `https://p.cldisk.com`，更新重新审查并批准digest，无新增依赖或标准能力。

- 目录/补全过程的160 hop滚动窗口与429暂停不再影响同包其他业务；补全入队前固定目录修订，过期任务启动前终止、合并前复核。
- 宿主将缓存及配置状态的写入、淘汰、持久化与失败恢复串行提交，脚本和网络取数仍可并行；恢复覆盖本次删除的旧缓存，身份失效时不恢复。提交队列按需创建并在空闲后释放，避免绑定到旧异步作用域。
- 通用归档不再把标题与ID相等解释为占位；显式标题更新被接受，学习通的占位判断和已有名称兜底留在脚本。
- 学习通成员取样不依赖详情成功，识别owner/admin/member及精确大整数；按官方SDK分页参数取有限样本；缺图不再被五分钟元数据缓存挡住。资料端点补齐官方客户端普通请求签名（随机nonce/时间戳/公开协议常量，不读取设备标识）；采用已知psize缩略图规格、按会话分配图片额度，并增加不含正文/身份的本地固定阶段探针。协议、许可及证据见[成员研究](../../school-scripts/xidian-chaoxing/research/group-members.md)。

自动验证：全量Flutter **2018项通过、11项既有跳过、0失败**；后续限流负例及最终打包边界 **11项通过**。另以实际0.7.5包在真实QuickJS完成 **6项合成对照**：1,025–16,384字节编码、四成员/四图/302跳转及MIME错配；旧严格匹配逻辑丢图，归一后字节与顺序均正确，不将合成PNG头payload当作有效图片解码证据。全量analyze无问题；学习通Node **72项**、SDK与工具类型检查、确定性增强包/夹具smoke通过。ARM64 release构建通过。测试均使用合成资料，不能代替学校或人工安全验收。

设备已保留应用数据覆盖至0.10.1，增强包经正常文件导入、网络范围审查及批准digest更新至0.7.5。有限只读探针确认群详情/成员可用；首轮资料HTTP200但data缺失/result不成功，补齐普通请求签名后，多个数字ID群已实际显示成员生成名称。头像入口多数302；取得的部分PNG/JPEG字节与响应MIME不对应，归一后才进入输出。补齐有界CDN跳转及类型归一后，探针确认头像装配/稀疏输出成功，原生列表也已实际显示头像。仍有CDN403及未被有限批次/预算覆盖的会话保持默认图标，不声称全部头像或全部账号验收成功。没有发送消息、签到或设备控制；核心/凭据/网络仍需人工实质审阅，未推送或合并。

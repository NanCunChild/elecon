# 规则 测试与验收

依据 [AGENTS](../../AGENTS.md)。旧版已[废弃归档](../archived/2026-10-31/docs/rules/testing.md)。

## 按变化验证

| 范围 | 应验证的内容 |
|---|---|
| 文档迁移 | 本地链接、迁移清单、废弃/提案标记、入口一致性、diff 与提交范围 |
| 学校脚本 | 合成/脱敏 fixture → 实际模块 → 标准输出；关键认证与桥接另测真实 QuickJS |
| 契约与生成器 | 输入/输出语义、版本兼容、未知/缺失值、生成物同步、非法输入 |
| 页面与模板 | 共享业务状态、loading/error/empty/stale/partial、分页与来源保留、l10n、适用 widget 回归 |
| 核心/授权/存储/网络 | 正负例、身份与安装变化、取消、网络范围、持久化失败；实现人工实质审阅 |
| 增强包与中继（落地时） | provider 绑定、权限、同名不同实体、缓存隔离/原始时效、限流/熔断/禁后台交互、禁命令自动回退 |
| V1 兼容 | 受影响的 official/Broker/Masker/DEV 门；共享 golden 限定的双端语义 |

## 数据和证据

CI 不请求真实学校接口、不操作真实设备，不使用真实学生或凭据。学校实际验收在明确授权和小预算下单独执行。源站速率、缓存 TTL、负载模型属于试点参数，不是实验结论；性能报告写明数据集、命中率、并发、窗口与测量结果。

新源码当前只有客户端生产执行面；Node 合成测试不等于服务器已能运行新包，更不等于原生桥接已验证。`school-scripts/<school>/tests/` 与客户端编译包测试分别承担模块和桥接验证。受影响的代码跑相应检查即可，文档变更不为刷绿重跑全部产品测试。

控制命令验证确认、撤销、只发送一次、未知态和禁自动重试。自动测试通过不代表人工安全签收、真实账户/设备验收或生产发布。不得删除断言以掩盖失败。

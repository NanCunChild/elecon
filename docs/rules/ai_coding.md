# 规则 AI 编程纪律

配合 [AGENTS](../../AGENTS.md)与[当前架构](../architecture.md)阅读。旧版已[废弃归档](../archived/2026-10-31/docs/rules/ai_coding.md)。

## 修改前

1. 读相关有效 ADR 和现有实现，区分受信源码、V1 兼容、尚未实现的提案。
2. 检查工作区，保护已有改动；不把别的任务代码或签收记录混进本次提交。
3. 核心或契约变化先有 ADR；已授权且被 ADR 覆盖的实现继续推进，不重复要求同一授权。

## 产出前自检

- [ ] 当前授权身份、网络与执行 digest 未被绕过；SDK 2 namespace 未被误称权限隔离。
- [ ] UI 未得到完整凭据库/主密钥；公网无凭据与私密数据。
- [ ] 新源码与 V1 的授权门分别验证；归档未被解释成可删除旧安全门。
- [ ] contract 变更有 ADR、字段含义与版本迁移；不以“最大兼容”允许任意有副作用输入。
- [ ] 背景执行、取消、退出/切校/更新时的失效仍成立。
- [ ] 新能力与模板有可复用边界；学校协议逻辑未进入通用 UI/宿主。
- [ ] 测试使用合成/脱敏数据；没有为过测试削弱断言。
- [ ] 新依赖声明来源、用途、许可证；不存在未经评估的原生能力。
- [ ] 已区分研究、已实现、自动回归、真机与人工签收，未伪造性能数字。
- [ ] 提交只含本次范围，附 `Assisted-by: Codex`。

安全敏感实现与测试须人工实质审阅后合并，自动测试不得自证安全签收。文档和研究可以按授权完成并提交；新的权限边界提案不能写成已具备的保护。

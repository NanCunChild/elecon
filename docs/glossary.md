# 当前术语与含义

依据 [ADR-041](adr/adr_041_current_architecture.md)。未来接口见 [ADR-042](adr/adr_042_providers_pages_enhancements.md)，以下“拟”表示未实现。

| 术语 | 确定含义 |
|---|---|
| 学校包 / 主学校包 | 用户安装授权的学校源码包；“主”角色拟由宿主显式绑定，当前注册表没有此角色 |
| adapter | 对接学校系统并归一化数据的逻辑；须注明是新受信脚本还是 V1 official bundle |
| capability | 可调用的业务操作 ID；参数、副作用和返回语义由契约定义 |
| schema | 参数或业务结果的数据类型与版本；不是页面，也不是服务提供者 |
| provider | 某包实现某能力的执行来源；已由 ADR-043 显式绑定默认/覆盖来源，更新不抢占 |
| 增强包 | 通过同名能力提供可选覆盖或补充实现的受信包；独立匿名权限角色仍待实现；不是隐式补丁或凭据继承 |
| feature / 页面 / 模板 | 客户端业务组合 / 路由与交互 / 可复用展示组件；均不等于脚本下发 Widget tree |
| query / command | 读取业务事实 / 改变远端状态；HTTP GET/POST 不能替代副作用分类 |
| 公共中继 | 只接入可公开读取和共享发布的数据，零学生凭据；拟新增业务缓存服务 |
| 校内授权中继 | 位于校内且获明确查询授权的服务；仍需身份隔离，当前为 501 stub |
| namespace | SDK 2 凭据寻址分组，不是访问控制；同校受信脚本可跨 namespace 寻址 |
| 身份 | 当前授权学校与账户语境；当前 SDK 学校级存储不能冒称已实现同校多账户全隔离 |
| 数据信封 | `elecon.envelope` 的标准结果包装，含来源与新鲜度；不等于签名对象 |
| bundle 信封 / 传输封套 | V1 签发清单 / 承载其签名与文件字节的 wire wrapper |
| 信封加密 | 平台凭据落盘的密钥包装术语，与前两种信封无关 |
| 包版本 / SDK 版本 / schema 版本 | 代码发布 / 宿主 API 兼容 / 业务数据语义，分别协商，不互相代替 |
| 已废弃 / archived | 不再指导新开发；保留历史，不意味着代码已删除或签收撤销 |
| Accepted / Landing / 安全签收 | 决策接受 / 实现程度 / 人工复核证据，三个独立维度 |

历史信任档、P0–P4 与 DEV/DEPLOY 细节仅供 V1 维护，见[旧术语档案](archived/2026-10-31/docs/glossary.md)。

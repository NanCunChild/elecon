# 西电学习通增强包

`0.2.0 / SDK 9`，分别绑定 `xidian_undergraduate` 和 `xidian_postgraduate`。提供学习通账号登录/本地退出、前台群消息接收窗口及扫码签到。安装授权、凭据、网络和取消边界见 [ADR-052](../../docs/adr/adr_052_community_accounts_and_chaoxing.md)。不覆盖基本包的教务登录和能力。

## 使用与支持范围

这是用户自行获取、检查和导入的第三方社区包，客户端不内置产物或推荐入口。选择对应本科/研究生学校后，在“学校脚本”通过“从文件导入”检查源码、HTTP/浏览器 origins、WebSocket origin 和相机权限后安装。可自行构建 `.elecon.json`：

```sh
npm run scripts:chaoxing -w tools
```

输出在本目录 `dist/`，不加入应用资产。卸载/禁用后，如无其他可执行消息来源，消息 Tab 消失。

0.1.1 修复页面跳转时过快耗尽重试的问题。消息页先通过学习通原站登录，脚本核验 UID/TID/FID 后仅保存该服务 Cookie。不会读取或尝试学校密码，不把学习通 UID 当作学号。账号记录在当前 Profile/学校的 `xidian.services` namespace、`chaoxing` key；namespace 不是同校脚本间的权限隔离。切换账号先本地退出；本地退出不代表服务端注销其他设备。

“获取消息”只接收一次最长 15 秒的当前群消息窗口，空闲 3 秒结束；最多 50 条，保留 uint64 消息 ID、群组、发送人和源站时间。没有历史补拉、私信、未读数、发消息或后台监听。协议 ACK 只用于服务队列接收，不发送用户已读操作。页面离开、应用后台、来源变化与身份变化会取消；正文不写持久缓存。

“扫码签到”登录后触发相机，严格接受固定超星扫码路径及活动 ID/enc。支持无额外挑战的 QR 活动，以及用户已选择地点的定位 QR 活动。两次查询都检查人脸、照片和验证码要求，未知要求保留为不支持。执行 analysis/preSign 后至多一次提交，再查状态；传输丢失不自动重发，无法核实时显示未知。协议客户端标识是脚本计算的字符串，不读取硬件标识或伪造当前位置。签到二维码不进入 params、日志或缓存；签退、纯定位活动、人脸和验证码续提不在本片范围。

0.2.0 按 [ADR-055](../../docs/adr/adr_055_checkin_locations_and_diagnostics.md) 使用 `attendance.checkin` 1.1：消息页提供最多 16 个可编辑地点按钮。名称、地址、经纬度由用户填写，坐标须来自签到服务使用的地点数据，不假定地图坐标系或自动转换。每次进入默认“不指定位置”，点击地点后用于下一次扫码；地点按 Profile、学校和来源分别保存。未填位置时，定位活动明确提示先选择地点。提交补齐来源页和异步请求头；二维码过期、位置未接受、人脸/验证码要求等显示固定诊断，日志只记录状态/原因枚举。服务要求的反模拟检测或附加验证不伪造，实际是否接受仍由服务核验。

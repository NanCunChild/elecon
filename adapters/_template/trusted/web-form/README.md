# 包内表单模板（SDK14）

本示例只在本机展示临时草稿，没有网络、持久保存、凭据或真实学校提交。Android 原生网页区域负责显示，业务代码在 QuickJS 内运行。

`webContent` 的 HTML 与源码一起打包并纳入 digest。文档脚本、事件属性和直接网络全部禁止；`browser.openContent(id)` 打开声明页面，`browser.content` 提供固定 DOM 操作，包括设置 HTML/文本/输入、属性、禁用状态和等待真实用户事件。不能在此模式用 `browser.evaluate`。作者需要更多节点时可以 `setHtml`，其中 HTML 仍为无脚本内容。

接学校表单时，在 `waitForEvent` 返回 true 后验证 `getValue` 的结果，再由 `ctx.fetch` 按已声明学校网络发送一次请求。检查源站的明确成功证据，连接中断且可能已提交时返回 `unknown`；不得由宿主恢复/刷新自动重发。不要把 `completed` 当作无条件成功，不把取消后的未知提交写成未提交。

同包多个页面共用 `web.content`，宿主固定传入 `pageId`。首页卡片只显示入口，明确点击打开后才执行。关闭、切身份和后台会取消，迟到结果不能改写新页面。模板默认总执行时间仍为 120 秒，应在脚本内给等待和网络预留预算。

完整远端学校网页透明嵌入和隐藏远端认证不由这个模板实现；本机文档的协议请求由脚本编写。参考 [ADR-073](../../../../docs/adr/adr_073_packaged_web_content.md)。
